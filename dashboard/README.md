# 대시보드 — 분석한 것을 한 화면에

결과물 폴더(`output/`)의 `상세페이지/원장.md` · `레퍼런스/원장.md` · `문의/문의함.csv` 를 읽어 **`output/dashboard.html` 한 장**을 만든다.
서버도 인터넷도 필요 없다 — 파일을 더블클릭하면 브라우저에서 열린다(`file://`).

```bash
python3 dashboard/make_dashboard.py          # 원장 → output/dashboard.html + 건별 report.html 다시 만들기
open output/dashboard.html                   # 맥에서 열기
```

- 원장을 고칠 때마다 **다시 실행**하면 된다. dashboard.html·report.html 은 매번 새로 쓰는 **결과물**이라 손으로 고치지 않는다(고쳐도 다음 실행에 덮인다). 정본은 원장과 각 폴더의 `.md` 다.
- 표준 라이브러리만 쓴다. 외부 라이브러리·CDN·웹폰트 0.
- 원장 읽기는 `shared/ledger.py` 의 `read()` 를 쓴다(원장 쓰기·읽기는 그 한 곳).

## 스킬이 지켜야 할 규격 (새 탭을 붙이는 스킬은 이것만 맞추면 된다)

### 1. 탭 폴더 하나 = 탭 하나
결과물 폴더 `output/` 안에 `<탭 폴더>/` 를 두고(위치는 `shared/paths.py` 의 `output_dir()` 한 곳) 그 안에 `원장.md` 한 장 + 건별 폴더를 둔다.

```
output/
  dashboard.html                  ← make_dashboard.py 가 만든다
  상세페이지/                     ← 탭 "상세페이지"  (스킬 detail-page)
    원장.md
    20261014_하루양말/
      원본/01.jpg 02.jpg …        ← 썸네일 후보
      전사.md
      시사점.md
      report.html                 ← make_dashboard.py 가 만든다
  레퍼런스/                       ← 탭 "레퍼런스"    (릴스 레퍼런스 스킬)
    원장.md
    20261014_<slug>/
      thumb.jpg                   ← 있으면 이것이 썸네일
      전사.md
      분석.md
      report.html
  문의/문의함.csv                 ← 문의 탭(보기 전용 · 아래 2-1)
```

탭은 `make_dashboard.py` 맨 위 `TABS` 목록에 한 줄로 등록돼 있다. 지금 등록된 것:

| 탭 이름 | 폴더 | report.html 에 싣는 md (이 순서) |
|---|---|---|
| 상세페이지 | `output/상세페이지/` | `시사점.md` → `전사.md` |
| 레퍼런스 | `output/레퍼런스/` | `분석.md` → `전사.md` |

폴더가 없거나 원장이 비어 있으면 그 탭은 "아직 없음"으로만 보인다(오류 아님).
목록에 없는 다른 `.md` 가 건별 폴더에 있으면 그 뒤에 이름순으로 붙는다.

### 2. 원장.md = 마크다운 표 한 장, **열 5개 고정** (대시보드는 머리글 글자가 아니라 **열 순서**로 읽는다)

```markdown
| 날짜 | 가게 | URL | 요약 | 폴더 |
|---|---|---|---|---|
| 2026-10-14 | 하루양말 | https://example.com/p/1 | 있음 3 · 약함 2 · 없음 2 — 가장 빈 곳: 상식파괴 | 20261014_하루양말 |
```

| 순서 | 뜻 | 규칙 |
|---|---|---|
| 1 | 날짜 | `YYYY-MM-DD` |
| 2 | 제목 | 카드 제목. 상세페이지 = 가게 이름 · 레퍼런스 = 계정/영상 이름. 머리글 글자는 탭마다 달라도 된다(**순서만** 고정) |
| 3 | URL | 원문 링크(`http`·`https` 만 링크가 된다) |
| 4 | 요약 | 카드에 보이는 한두 줄 |
| 5 | 폴더 | 원장.md 옆의 건별 폴더 이름. `[이름](이름/)` 링크 꼴이어도 읽는다 |

- 🛑 **맨 아래에 한 줄 추가만 한다** — `shared/ledger.py` 의 `append(원장경로, {열: 값})` 로. 표 전체를 다시 쓰지 않는다.
- 🛑 칸 안에 `|` 를 쓰지 않는다(표가 깨진다) — `/` 나 `·` 로.
- 화면에는 **최근 줄이 먼저**(원장 아래쪽이 위로) 보인다.

### 2-1. 문의 탭 (보기 전용 · 원장이 아니라 csv)
문의 스킬이 만드는 `output/문의/문의함.csv`(utf-8, 엑셀 저장본의 BOM 도 읽음)를 읽어 세 가지만 보여 준다.
열(정본 = `.claude/skills/inquiry-inbox/scripts/common.py` 의 `COLUMNS`): `id · 채널 · 종류 · 접수일 · 상품 · 고객(가림) · 문의 원문 · 답변 · 상태` — 대시보드가 쓰는 건 `채널 · 접수일 · 상품 · 문의 원문 · 상태`.

1. 상태별 개수 — 스크립트가 쓰는 값은 `미답변` 하나. 사장님이 바꿔 적은 상태(예: `답함`)는 나오는 대로 센다
2. 채널별 미답변 수
3. 오래 기다린 순 미답변 목록 — 접수일 · 며칠째 · 채널 · 상품 · 원문 앞 60자 (최대 50줄)

- 고객 칸은 화면에 싣지 않는다.
- 🛑 **보내기 버튼·입력 폼·발송 코드 0.** 이 묶음에는 답변 보내기 코드가 없다 — 답은 사장님이 각 채널 관리자에서 보낸다. API 로도 가능하지만 위험해서 재료만 둔다(`.claude/skills/inquiry-inbox/완성하기.md`).
- csv 가 없으면 "아직 모은 문의 없음 — 문의 스킬을 실행하세요"만 보인다.

### 3. 썸네일 고르는 순서
건별 폴더에서 처음 찾은 것 하나:
1. `thumb.jpg` / `thumb.jpeg` / `thumb.png` / `thumb.webp` / `thumb.gif`
2. `원본/` 안의 이미지 중 이름순 첫 장
3. 건별 폴더 바로 아래 이미지 중 이름순 첫 장
4. 없으면 회색 칸

### 4. report.html
건별 폴더의 md 들을 위 순서로 이어 붙여 html 한 장으로 만든다. 지원하는 마크다운:
제목(`#`~`####`) · 굵게(`**`) · 기울임(`*`) · 인라인 코드 · 목록(`-`·`1.`) · 표 · 인용(`>`) · 가로줄(`---`) · 코드 블록 · 링크 ·
**`[이미지: …]` 줄**(장면 묘사 — 회색 상자로 보인다).
그 밖의 문법은 글자 그대로 보인다(깨지지는 않는다).
