# 상세페이지 분석 — 사용법

## 1. 목적
옆집(또는 내) 상세페이지 한 장이 **왜 팔리는지** 말로 풀어낸다.
위에서 아래로 무엇이 적혀 있고 무엇이 보이는지 글로 옮긴 뒤, 마케팅 7원칙에 대 보고
"이 페이지는 무엇을 잘하고 무엇이 비었나", 그리고 **내 상세에서 오늘 고칠 것 3개**를 받는다.
여러 페이지 비교표는 만들지 않는다 — 한 번에 한 페이지를 깊게 본다.

## 2. 산출물
건마다 폴더 하나 `output/상세페이지/<날짜>_<가게>/` 에:

| 파일 | 무엇 |
|---|---|
| `전사.md` | 상세페이지를 위→아래 글로 옮긴 것. 글씨는 그대로, 사진은 `[이미지: …]` 한 줄 묘사, 강조는 굵게 |
| `시사점.md` | 7원칙 판정표(있음 / 약함 / 없음) · 손님 의심표 · 표현 주의 · **오늘 고칠 것 3** |
| `report.html` | 위 둘을 보기 좋게 한 장으로 (더블클릭하면 열림) |
| `원본/` · `조각/` | 내려받은 상세 이미지와, 읽기 좋게 자른 조각 |

그리고 한곳에 모아 보는 것 두 개:
- `output/상세페이지/원장.md` — 한 건 = 한 줄 (날짜 · 가게 · URL · 7원칙 요약 · 폴더)
- `output/dashboard.html` — 지금까지 분석한 페이지를 썸네일 카드로 (인터넷 없이 열림)

## 3. 스킬의 작동 방식
1. **모으기** — 사장님이 쓰던 크롬에서 상세페이지를 열고, 펼치기 버튼을 누르고, 끝까지 스크롤해 상세 이미지 주소를 모은다(반자동크롤러 스킬).
2. **내려받기** — 이미지를 순서대로 `원본/` 에 저장한다.
3. **자르기** — 세로로 아주 긴 이미지를 1,600px 조각으로 자른다. 작은 글씨까지 읽기 위해서다.
4. **옮겨 적기** — 클로드가 조각을 한 장씩 직접 보고 `전사.md` 에 옮긴다. 안 보이는 건 `[불확실]` 이라고 적고 지어내지 않는다.
5. **시사점** — `전사.md` 만 보고(+ `브랜드_SSOT.md` 가 채워져 있으면 그것도) 7원칙으로 판정하고 오늘 고칠 것 3개를 쓴다. 아직 비어 있으면(템플릿 그대로) "브랜드_SSOT.md 가 비어 있어 일반 제안" 이라고 밝히고 일반 제안으로 쓴다.
6. **기록** — 원장에 한 줄 더하고 대시보드를 다시 만든다.

외부 AI 서비스나 API 키를 쓰지 않는다. 클로드 코드 안에서 다 끝난다.

## 4. 설치법

0. 레포 받기·클로드 코드 열기 = 루트 [README 설치](../../../README.md#4-설치). 그다음 클로드 코드에 **"이 스킬 설치 도와줘"** 라고 하면 `python3 shared/doctor.py detail-page` 로 아래 단계를 ✅/❌ 점검하며 ❌ 인 것만 하나씩 안내합니다. **아래 번호 = 점검 번호.**

1. **파이썬 3.9 이상** — 맥에 보통 들어 있습니다(없으면 처음 실행할 때 맥이 설치 창을 띄웁니다).
2. **Node(`npx`)** — 없으면 [nodejs.org](https://nodejs.org) 에서 LTS 설치 → 터미널 새로 열기.
3. **크롬 버전(144 이상)** — 크롬 연결 — 반자동크롤러 사용법의 [설치법](../semi-auto-crawler/사용법.md#4-설치법)을 따르세요(이미 했으면 건너뜀).
4. **크롬 연결 설정(`.mcp.json`)** — 크롬 연결 — 반자동크롤러 사용법의 [설치법](../semi-auto-crawler/사용법.md#4-설치법)을 따르세요(이미 했으면 건너뜀).
5. **파이썬 이미지 도구(pillow)** — 터미널에서 한 번: `python3 -m pip install -r .claude/skills/detail-page/requirements.txt`
6. (선택) **브랜드_SSOT.md** — 비어 있어도(템플릿 그대로) 작동합니다. 채우면 결과가 내 가게에 맞춰집니다. "브랜드_SSOT.md 같이 채우자" 라고 하면 대화로 함께 채웁니다. 1절(우리 가게)·2절(누가 사나요)·3절(파는 것)·9절(하지 않는 말)만 채워도 "오늘 고칠 것"이 내 가게 기준이 됩니다.

API 키는 **필요 없습니다.**

**실행 한 줄** — 클로드 코드에:
> 이 상세페이지 분석해줘 https://…

다 끝나면 대시보드가 열린다. 나중에 다시 보려면 `output/dashboard.html` 을 더블클릭.

## 5. 안 될 때
| 증상 | 이렇게 |
|---|---|
| "pillow 가 없습니다" | 4절 5번의 `python3 -m pip install …` 한 줄을 실행 |
| 크롬이 안 붙는다 | 반자동크롤러 사용법의 "안 될 때"부터 |
| "텍스트형"이라고 한다 | 상세가 이미지가 아니라 글이다 — 클로드가 페이지 글을 그대로 옮긴다(정상) |
| "미판정" · 이미지 0장 | 처음 보는 쇼핑몰 구조다. 클로드가 보여 주는 후보 중 상세 영역을 함께 고르면 된다 |
| 다운로드 실패(403) | 쇼핑몰이 바깥 다운로드를 막았다. 크롬에서 그 이미지를 열어 직접 저장해 `원본/` 에 같은 번호로 넣고 "이어서 해줘" |
| 조각이 60개 넘는다고 묻는다 | 아주 긴 상세다. 오래 걸려도 되면 "계속", 아니면 앞부분만 하자고 말하기 |
| 대시보드에 안 보인다 | 레포 맨 위에서 `python3 dashboard/make_dashboard.py` 를 다시 실행. "경고:" 줄이 나오면 원장 그 줄의 칸 수(5개)와 폴더 이름을 확인 |
| 대시보드 썸네일이 회색 | 그 건 폴더의 `원본/` 이 비었다 — 이미지가 안 받아진 것 |
