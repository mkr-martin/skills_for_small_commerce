# 상세페이지 분석 (세션판)

이 세션의 클로드가 상세 이미지를 **직접 Read 해서** 읽는다. 외부 AI API·키를 쓰지 않는다.
산출물은 **둘뿐** — `전사.md` · `시사점.md`. 비교표·여러 페이지 교차 분석·기계용 JSON 은 만들지 않는다.

공통 규칙(`브랜드_SSOT.md`(선택) · 원장 · 키 · 쓰기 안전 · 스크립트 불러오기) = [루트 CLAUDE.md](../../../CLAUDE.md) — 여기 다시 적지 않는다. 명령은 모두 레포 맨 위에서 실행한다(경로가 레포 맨 위 기준). 스킬 폴더 = `.claude/skills/detail-page/` (아래 `$S`).

## 폴더
결과물은 레포 맨 위 `output_detail-page/` 아래(경로는 `shared/paths.py` 한 곳에서만 정한다).
```
output_detail-page/
  원장.md                         ← 한 건 = 한 줄 (맨 위에 추가)
  <yyyymmdd_hhmm>_<가게>/         ← 건 폴더 (run_dir 이 시각을 붙여 만든다)
    수집.json                     ← 1단계 결과
    원본/01.jpg 02.webp …         ← 2단계
    조각/001_01.png … 조각목록.txt ← 3단계
    전사.md                       ← 4단계
    시사점.md                     ← 5단계
```
건 폴더는 시작할 때 한 번만 만들고 끝까지 그 경로를 쓴다(아래 `<건>`):
```bash
python3 -c "from shared.paths import run_dir; print(run_dir('detail-page', '<가게>'))"
```
`<가게>` = 가게 이름(띄어쓰기는 `_` 로). 같은 가게를 또 해도 시각이 달라 폴더가 겹치지 않는다.

## 0. 준비 확인 (처음 한 번)
- `python3 -c "import PIL"` 이 실패하면 → `python3 -m pip install -r $S/requirements.txt`
- 사장님께 URL 과 가게 이름(폴더 이름에 쓸 짧은 이름)을 확인한다.

## 1. 수집 — 내 크롬 (반자동크롤러 스킬)
1. **`semi-auto-crawler` 스킬을 먼저 따른다** — 사장님이 쓰던 크롬을 붙잡아 새 탭에서 URL 을 연다. 로그인·성인인증·캡차가 나오면 사장님 손에 넘긴다(우회하지 않는다).
2. `$S/scripts/collect_images.js` 의 함수를 크롬 도구의 스크립트 실행(evaluate_script)에 **통째로** 넣는다. 스니펫이 펼치기 버튼을 누르고 끝까지 스크롤한 뒤 상세 이미지 주소를 돌려준다.
3. 돌려받은 JSON 을 그대로 `<건 폴더>/수집.json` 에 저장한다.
4. `branch` 와 `warnings` 를 보고 갈래를 탄다:
   - `텍스트형` (이미지 세로 합 8,000px 미만) → 이미지 전사 대신 **페이지 글을 읽어** 그대로 `전사.md` 에 옮기고 5단계로.
   - `미판정` 이나 `images` 0장 → 멈추고 사장님께 `ladder`(조상 사다리)를 보여 주며 상세 영역을 함께 고른다. 셀렉터를 정하면 스니펫의 컨테이너 부분을 그 자리에서 고쳐 다시 돌린다.
   - 차단 문구 경고 → 사장님 크롬이 맞는지, 로그인됐는지 확인.
   - `strips_est` 가 60 을 넘으면 → 읽기 전에 사장님께 "조각이 많아 오래 걸린다"고 확인받는다.

## 2. 다운로드
```bash
python3 $S/scripts/download.py <건>/수집.json --out <건>/원본 --referer "<URL>"
```
실패가 있으면 번호가 빈다(순서가 빠진 것) — 사장님께 알리고, 빠진 채로 갈지 묻는다.
다운로드가 계속 막히면(403) 크롬 탭에서 그 이미지를 열어 사장님이 직접 저장해 `원본/` 에 같은 번호로 넣어도 된다.

## 3. 조각
```bash
python3 $S/scripts/slice.py <건>/원본 --out <건>/조각
```
세로 1,600px · 겹침 240px. 결과 개수를 사장님께 한 줄로 알린다.

## 4. 전사 — 조각을 한 장씩 Read
- 규칙: **`$S/prompts/전사_규칙.md` 를 먼저 읽고 그대로 따른다.**
- `조각/` 의 png 를 **이름순으로 한 장씩** Read → 본 것을 `전사.md` 끝에 이어 쓴다. 몇 장마다 파일에 쓰고 넘어간다(다 읽고 한 번에 쓰지 않는다 — 길면 앞 내용을 잊는다).
- 🛑 **보이는 것만 옮긴다.** 안 보이거나 흐리면 `[불확실]`. 전사본에 없는 것은 나중 단계에서도 쓰지 않는다.
- 다 쓰면 조각 수와 전사한 조각 수가 같은지 확인한다. 다르면 빠진 조각을 마저 읽는다.

## 5. 시사점
- 규칙: **`$S/prompts/시사점_규칙.md` 를 읽고 그 형식 그대로** `시사점.md` 를 쓴다.
- 입력은 `전사.md` 와 레포 맨 위 `브랜드_SSOT.md` 뿐. 이미지를 다시 보지 않는다. 먼저 `python3 shared/store_profile.py` 로 채워졌는지 본다 — "비어 있음(템플릿 그대로)" 이면 5절(오늘 고칠 것) 머리에 "브랜드_SSOT.md 가 비어 있어 일반 제안" 이라고 적고 일반 제안으로 채운다(규칙 파일 그대로).

## 6. 원장 한 줄
원장 규칙은 루트 CLAUDE.md §3. 장부는 맨 위에 쌓는다. 추가는 `shared/ledger.py` 로만:
```bash
python3 shared/ledger.py output_detail-page/원장.md '{"날짜": "2026-10-14", "가게": "하루양말", "URL": "https://…", "7원칙 요약": "있음 3 · 약함 2 · 없음 2 — 가장 빈 곳: ②상식파괴", "폴더": "20261014_1530_하루양말"}'
```
- 열 5개 · 이 순서 고정: `날짜 | 가게 | URL | 7원칙 요약 | 폴더` (`폴더` = 건 폴더 이름 그대로).
- 7원칙 요약 = 시사점.md 2절의 집계 줄 + 가장 빈 원칙 하나.

## 7. 마무리
사장님께 건 폴더의 `시사점.md` 를 열어 보시라고 알리고(경로를 그대로 적는다), 시사점의 "오늘 고칠 것 3"을 대화로 짧게 전한다.
