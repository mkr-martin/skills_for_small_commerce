## §1. 릴스 공식 18 (분석 어셈블 체계)

잘 나간 콘텐츠는 이 중 **3~4개 이상**이 겹쳐 적용돼 있다는 것이 원 체계의 전제.

| # | 공식 | 한 줄 |
|---|---|---|
| 1 | **분석 어셈블 (쪼개기 이론)** | 조회수 100만+ 콘텐츠를 쪼개 성공 패턴을 찾는다 — 나머지 17개 공식의 메타 공식 |
| 2 | **숫자의 원칙** | 추상 대신 구체적 숫자를 카피에 — 더 선명하고 명확하게 느껴짐 |
| 3 | **특이한 장면** | 신기하고 범상치 않은 장면으로 시작 — 강렬한 비주얼로 스크롤 멈추기 |
| 4 | **유행하는 음악** | 트렌드 음악으로 알고리즘 노출·시청 완료율 상승 |
| 5 | **유행하는 장면** | 핫한 포맷 차용 — 익숙한 형식이 더 오래 머물게 함 |
| 6 | **박자에 맞추기** | 음악 비트에 맞춘 화면 전환 — 조화가 몰입을 만든다 |
| 7 | **1초의 법칙** | 첫 1초 안에 강렬한 무언가로 시선 사로잡기 |
| 8 | **어? 잘못봤나?** | 뜻밖의 장면 삽입으로 재감상 유도 — 반복 재생이 알고리즘 점수로 |
| 9 | **스토리텔링** | 정보 나열 대신 기승전결 — 끝까지 보게 만들기 |
| 10 | **감성** | 감성적 연출·카메라 무빙 — 감정이 움직여야 행동이 따라옴 |
| 11 | **논란거리 제공** | 약간의 논란 여지로 댓글 활성화 — 높은 댓글 수 = 알고리즘 탑승 |
| 12 | **언매칭** | 전혀 안 어울리는 조합으로 호기심 자극 — 반전 요소 |
| 13 | **귀여움** | 완벽함보다 실수·귀여움으로 친근감 — 인간적인 콘텐츠가 공감·신뢰 |
| 14 | **특이한 배경** | 독특한 로케이션 — 장소의 분위기가 제품 이미지에 전이 |
| 15 | **표본이론** | 타겟을 좁힌 표현보다 누구나 궁금해할 대중적 언어로 |
| 16 | **가치 깎기** | 신비롭고 예쁜 대상의 가치를 약간 깎아 흥미 유발 (도 넘지 않게) |
| 17 | **꼬아주기** | 유행 릴스 그대로 말고 창의성 20% 첨가 — 80% 익숙 + 20% 새로움 |
| 18 | **팔로워할 이유** | 계속 볼 가치 제공으로 팔로우 유도 — 꿀팁 후 "더 받으려면 팔로우" |

## §2. 훅킹 문구 6유형 (원본 164건 증류)

원본 164건을 유형별로 묶어 **유형당 대표 템플릿만** 남겼다. `[대괄호]`=치환 슬롯, N=숫자 슬롯.

### 2-1. 정보성 훅 (원본 81건 — 최다. 정보 격차 + 구체 숫자)
- `[직업]이 추천하는 [OO템] 바로 알려드릴게요`
- `의외로 잘 모르는 [주제] N가지` / `진작 알았으면 좋았을 [주제] N가지`
- `99%가 모르는 [물건/서비스] 싸게 사는 법`
- `절대 따라하지 마세요 X` / `절대금지 [아이템] N가지`

### 2-2. 비교성 훅 (원본 25건 — vs 구조·순위)
- `일반[제품] vs 특정[제품]` / `상상 vs 현실` / `before vs after`
- `[주제] 티어리스트` / `[주제] 순위 매기기`
- `POV: [공감가는 상황명]`

### 2-3. 통념 반박형 훅 (원본 14건 — 손실 회피 + 상식파괴)
- `이거 없으면 [금액] 날립니다` / `[이거] 모른다면 지금까지 손해보던겁니다`
- `다쓴 [물건] 절대 그냥 버리지 마세요`
- `[주제] 믿으면 안되는 이유` / `요즘에는 [이런거] 안합니다`

### 2-4. 스토리텔링 훅 (원본 16건 — 선언·반전 서사)
- `저는 지금부터 [기한] 안에 [목표]를 이룰 겁니다!` (선언 → 결과 궁금증)
- `[유명한 곳]에서 연락이 왔다. 내 제품을 [목적]으로 사용하고 싶다는 연락이었다.`
- `생산하자마자 전량 폐기했습니다!` (충격 선언)
- `나는 실패한 [직업]이다` (자기 고백)

### 2-5. 권위형 훅 (원본 13건 — 전문가·경력·소득 인증)
- `현직 [직업]이 자주 쓰는 N가지`
- `월 [소득] [직업]이 숨기는 비밀 N가지`
- `[전문가]의 [특정] 생활 루틴`

### 2-6. 일상 공개형 훅 (원본 15건 — 루틴·브이로그형 관찰 욕구)
- `[직업]의 [모닝/일상/저녁] 루틴` / `[나이][직업]의 하루`
- `N년차 [직업]의 월급 공개`
- `몰래 [목표] 하기 N일차`

## §3. 오프닝 패턴 15

영상 첫 발화(또는 마무리 떡밥)의 상용구. 원본 15건 전량.

1. "아니 여러분 ~" 하고 시작
2. "그거 아세요? ~" 하며 시작
3. 영상 후킹 ~ 으로 시작
4. "이게 후킹입니다 ~" 하며 시작
5. "알고보니 ~ 다음화에 계속" 으로 마무리
6. "과연 [OO]의 운명은?" 으로 마무리
7. "여러분 [주제] 좋아하세요? ~" 하고 시작
8. "완전 내꺼 잖아?! ~" 하고 시작
9. "[상황] 이라면 N가지만 기억하세요!" 하고 시작
10. "여러분 제가 며칠전에…" 하고 시작
11. "[장소]에 항의하러 갑니다~" 하며 시작
12. "해외에서 난리난 ~" 하며 시작
13. "이거 저만 몰랐나요? ~" 하고 시작
14. "[OO년생] 존예 [직업]" 으로 시작
15. "거봐요 제가 진짜 좋다고 했잖아요~" 라며 시작
