# 릴스 레퍼런스 분석 — 사용법

## 1. 목적
잘 된 릴스를 보고 "좋다"에서 멈추지 않고, **뭐가 먹혔는지 이름을 붙여** 내 가게 영상에 옮기기 위한 스킬이다.
"정보성 훅 + '그거 아세요?' 오프닝 + 구체 숫자" 처럼 이름이 붙어야 다음 영상에서 똑같이 써먹을 수 있다.

## 2. 산출물
릴스 한 건마다 폴더 하나, 그리고 전체 목록 한 장.

```
output_reels-reference/
  원장.md                  ← 한 줄 = 한 건 (날짜 · 계정·영상 · URL · 요약 · 폴더)
  20261014_1530_AbCdEf123/
    원본.mp4               ← 받은 영상
    thumb.jpg              ← 썸네일
    전사.md                ← 캡션 + 영상 속 말·화면 글자(시간순)
    분석.md                ← 아래 표
```

`분석.md` 에 들어가는 것:
| 칸 | 뜻 |
|---|---|
| 훅 유형 | 6가지 중 하나 — 정보성 · 비교성 · 통념 반박형 · 스토리텔링 · 권위형 · 일상 공개형 |
| 오프닝 | 14가지 첫마디 중 하나 — 예) "그거 아세요?" |
| 공식 | 릴스 공식 10가지 중 최대 3개 — 예) 첫 프레임 패턴 차단 · 구체 숫자 |
| 3초 훅 | 첫 3초에 실제로 나온 말·글자 원문 |
| 씬 표 | 몇 초~몇 초 · 역할(후킹·전개·전환·CTA) · 자막 |
| 태그 | 최대 4개 |
| 우리 가게 훅 후보 3 | `브랜드_SSOT.md` 의 파는 것·소구점·말투로 만든 첫 3초 문구 세 개(아직 비어 있으면(템플릿 그대로) "브랜드_SSOT.md 가 비어 있어 일반 제안" — 빈칸 들어간 일반 문구) |

결과는 그 폴더의 `분석.md` 를 열어 확인한다.

## 3. 스킬의 작동 방식
1. **받는다** — 릴스 영상은 인스타 로그인 없이는 못 받는다. 그래서 **내 크롬에 이미 로그인된 인스타**를 빌려 영상을 내려받는다(비밀번호를 따로 넣지 않는다).
2. **보여 준다** — 영상을 통째로 Gemini(구글 AI)에 올려 보게 한다. 말·자막·장면 전환까지 본다.
3. **이름 붙인다** — 이 폴더의 `패턴집.md`(공식 10 · 훅 6 · 오프닝 14)에 있는 이름으로만 고른다. 안 맞으면 "해당 없음". 영상에 없는 걸 지어내지 않게 막아 두었다.
4. **옮긴다** — `브랜드_SSOT.md` 가 채워져 있으면 거기 적힌 내용만 근거로 우리 가게용 훅 후보 3개를 쓴다. 아직 비어 있으면(템플릿 그대로) 일반 제안이라고 밝히고 빈칸 들어간 문구로 쓴다.
5. **남긴다** — 폴더에 저장하고 원장 맨 아래에 한 줄을 붙인다.

영상을 못 받으면 **캡션 기준**으로 바꾼다 — 클로드가 반자동크롤러로 내 크롬에서 캡션과 화면 글자만 읽어 분석한다. 이때는 결과 맨 위에 "⚠️ 캡션 기준 분석" 이라고 적힌다(말·장면은 못 본 분석이라는 뜻).

## 4. 설치법

0. 레포 받기·클로드 코드 열기 = 루트 [README 설치](../../../README.md#4-설치). 그다음 클로드 코드에 **"이 스킬 설치 도와줘"** 라고 하면 `python3 shared/doctor.py reels-reference` 로 아래 단계를 ✅/❌ 점검하며 ❌ 인 것만 하나씩 안내합니다. **아래 번호 = 점검 번호.**

1. **파이썬 3.9 이상** — 맥에 보통 들어 있습니다(없으면 처음 실행할 때 맥이 설치 창을 띄웁니다). 3.10 이상이면 더 좋습니다(인스타 받기 도구 새 버전).
2. **크롬 버전(144 이상)** — 크롬 버전 확인은 반자동크롤러 사용법의 [설치법](../semi-auto-crawler/사용법.md#4-설치법)을 따르세요(이미 했으면 건너뜀). 크롬에 **인스타 로그인**이 돼 있어야 영상을 받습니다(반자동크롤러 셋팅까지 돼 있으면 캡션 기준 모드도 씀).
3. **파이썬 패키지(google-genai · yt-dlp)** — 터미널에서 한 번: `python3 -m pip install -r .claude/skills/reels-reference/requirements.txt`
4. **Gemini API 키**(꼭 필요) — 클로드 코드에 **"키 넣어줘"** → 뜨는 창에 붙여넣기(발급 방법 = 루트 [README '키 발급'](../../../README.md#5-키-발급)) · 🛑 키는 채팅창에 붙여넣지 않습니다.
5. (선택) **브랜드_SSOT.md** — 비어 있어도(템플릿 그대로) 작동합니다. 채우면 결과가 내 가게에 맞춰집니다. "브랜드_SSOT.md 같이 채우자" 라고 하면 대화로 함께 채웁니다. 비어 있으면 훅 후보가 "브랜드_SSOT.md 가 비어 있어 일반 제안" 으로 나옵니다.

**실행 한 줄** (클로드 코드에 말하기)
```
이 릴스 레퍼런스 분석해줘 https://www.instagram.com/reel/AbCdEf123/
```

## 5. 안 될 때
| 보이는 말 | 이유 | 이렇게 |
|---|---|---|
| "Gemini API 키가 없어서 멈췄어요" | 키를 아직 안 넣음 | "키 넣어줘" → 창에 붙여넣기. 키는 채팅으로 주지 않는다 |
| "Gemini 가 키를 받아주지 않았어요" | 키 오타·삭제·결제 한도 | Google AI Studio 에서 키를 새로 만들고 "키 넣어줘" → 덮어쓰기 |
| "필요한 프로그램이 아직 안 깔려 있어요" | 처음 한 번 설치를 안 함 | 4절 3번 설치 한 줄 실행 |
| 설치 때 `externally-managed-environment` | 홈브루 파이썬이 전체 설치를 막음 | `python3 -m venv .venv && .venv/bin/pip install -r .claude/skills/reels-reference/requirements.txt` 후 `python3` 대신 `.venv/bin/python3` 으로 실행해 달라고 클로드에게 말한다 |
| 맥이 "크롬 저장소에 접근하려 합니다" 를 물음 | 크롬 로그인을 빌려 쓰는 순간 | **허용**(또는 항상 허용). 거부하면 영상을 못 받는다 |
| "영상을 받지 못했어요" | 크롬에서 인스타 로그아웃 · 비공개/삭제 릴스 · 받기 도구가 낡음 | 크롬에서 인스타에 다시 로그인 → 다시 실행. 그래도 안 되면 클로드가 캡션 기준으로 바꿔 준다. 받기 도구 갱신: `python3 -m pip install -U yt-dlp` |
| "[주의] 파이썬이 3.10 보다 낮아요" | 맥 기본 파이썬(3.9)은 받기 도구 새 버전을 못 씀 | `brew install python` 으로 새 파이썬을 깔고 설치 한 줄을 다시 |
| "300초 넘는 영상은 받지 않아요" | 5분 넘는 영상 | 릴스용 스킬이다. 긴 영상은 대상이 아니다 |
| "분석에 실패했어요" | 일시 오류·응답 잘림 | 한 번 더 실행(새 폴더로 처음부터 다시 돈다). 폴더에 `gemini_원문.txt` 가 있으면 그게 받은 응답 |
| 훅 후보가 뻔하다 · "일반 제안" 이라고 나온다 | `브랜드_SSOT.md` 가 아직 비어 있음(템플릿 그대로) | 소구점·타깃·말투를 채우고 다시 |

비용: 키 주인(사장님) 구글 계정에 청구된다. 릴스 한 건은 대략 수십 원 이하로 실측됐다(2026년 가을 요금 기준 — 구글 요금은 바뀔 수 있다).
