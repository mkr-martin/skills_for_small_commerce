# 릴스 레퍼런스 분석

공통 규칙(`브랜드_SSOT.md`(선택) · 원장 · 키 · 쓰기 안전 · 스크립트 불러오기) = [루트 CLAUDE.md](../../../CLAUDE.md) — 여기 다시 적지 않는다.

## 하는 일
인스타 릴스 URL 하나 → 영상을 받아(내 크롬의 인스타 로그인 재사용) Gemini 가 영상째 보고 분석 → 폴더에 저장 + 원장 한 줄.
분석 사전은 이 폴더의 `패턴집.md`(릴스 공식 18 · 훅 유형 6 · 오프닝 15), 태그 목록은 `tag_axes.json`, 응용 근거는 레포 맨 위 `브랜드_SSOT.md`(선택 — 아직 비어 있으면(템플릿 그대로) 훅 후보가 "브랜드_SSOT.md 가 비어 있어 일반 제안" 으로 나온다).

## 순서
1. **실행한다**(레포 맨 위에서). 사장님이 메모를 줬으면 `--note "…"` 로 붙인다.
   ```
   python3 .claude/skills/reels-reference/scripts/analyze_reel.py "<릴스 URL>"
   ```
2. **종료 코드로 갈린다.**
   - `0` 성공 → 3번으로.
   - `2` 준비물 부족(키 없음·패키지 없음·주소 틀림) → 스크립트가 찍은 문장을 그대로 보여 주고 멈춘다(키 다루는 법은 루트 CLAUDE.md §4).
   - `3` 영상 받기 실패 → **캡션 기준 모드**(아래 §캡션 기준).
   - `4` 분석 실패 → 문장을 보여 주고, 한 번만 다시 실행해 본다(같은 폴더를 이어 쓴다). 또 실패하면 멈춘다.
3. **대시보드를 다시 만든다**(건별 `report.html` 도 여기서 생긴다).
   ```
   python3 dashboard/make_dashboard.py
   ```
4. **보고한다** — `분석.md` 를 읽고 세 줄로: 훅 유형·오프닝·공식 / 3초 훅 원문 / 우리 가게 훅 후보 3. 캡션 기준이었으면 첫 줄에 그 사실을 먼저 말한다. 끝에 `open output/dashboard.html` 을 권한다.

## 캡션 기준 모드 (영상을 못 받았을 때)
1. 스킬 `semi-auto-crawler`(반자동크롤러)로 사장님 크롬에서 그 릴스 주소를 연다 — **읽기만**(🟢).
2. 화면에 보이는 **캡션 전문 + 화면에 찍힌 글자**(자막·썸네일 문구)만 받아 적는다. 댓글·다른 게시물은 넣지 않는다. 안 보이는 것을 짐작해 채우지 않는다.
3. 스크립트가 알려 준 경로(`output/레퍼런스/<날짜>_<코드>/캡션.txt`)에 저장하고 다시 실행한다.
   ```
   python3 .claude/skills/reels-reference/scripts/analyze_reel.py "<릴스 URL>" --caption-file "<그 캡션.txt 경로>"
   ```
4. 결과 `분석.md` 머리에 "⚠️ 캡션 기준 분석" 이 자동으로 붙고, 원장 요약 칸도 `(캡션 기준)` 으로 시작한다. 보고할 때도 첫 줄에 말한다.

## 결과물
결과물 폴더 규칙 = 루트 CLAUDE.md §2(전부 `output/` 아래).
```
output/레퍼런스/
  원장.md                       ← 한 줄 = 한 건 (스크립트가 맨 아래에 붙인다)
  20261014_AbCdEf123/
    원본.mp4                    ← 받은 영상(캡션 기준이면 없음)
    thumb.jpg                   ← 썸네일(대시보드 카드 사진)
    전사.md                     ← 캡션 + 말·화면 글자(시간순)
    분석.md                     ← 훅 유형 · 오프닝 · 공식 · 3초 훅 · 씬 표 · 태그 · 우리 가게 훅 후보 3
    analysis.json               ← Gemini 응답 원본(보관용)
    report.html                 ← python3 dashboard/make_dashboard.py 가 만든다
```

## 원장
- 열 5개: `날짜 | 계정·영상 | URL | 요약 | 폴더`. 훅 유형·오프닝·공식·태그·한 줄 요약은 **요약 칸 하나에** `·` 로 이어 적힌다. 줄 추가는 스크립트가 `shared/ledger.py` 로 한다.

## 지키는 것
- 자료에 있는 것만 말한다 — 분석 프롬프트에 "보지 못한 것은 null" 규칙이 들어 있다. 사장님께 보고할 때도 `분석.md` 에 없는 내용을 덧붙이지 않는다.
- 남의 릴스 영상은 **분석용 개인 보관**이다. 다시 올리거나 퍼뜨리지 않도록 안내한다.
