# 반자동크롤러 — 원리 · 초기 셋팅 (SKILL.md 에서 분리)

## 원리 — 왜 이게 되나

새 브라우저를 띄우면 **빈 깡통**이다 — 로그인·쿠키·사용기록이 없어서, 내가 로그인해야 보이는 화면은 비어 보인다.
그래서 **내가 매일 쓰는 크롬을 그대로** 쓴다. 목적은 사람이 보는 그 화면을 사람 옆에서 읽는 것이다.

> 함정: `--remote-debugging-port`는 **기본 프로필에선 무시된다**(Chrome 136+ 보안 변경). 그래서 예전 방식은 결국 빈 브라우저가 됐다.
> **Chrome 144의 옵트인 화면**(`chrome://inspect/#remote-debugging`)이 그 끝을 풀었다 — 쓰던 프로필 그대로 연결을 연다.
> 붙는 쪽은 `chrome-devtools-mcp`의 **`--autoConnect`** 설정이 담당한다(크롬 설정이 아니라 **MCP 서버 설정** — 헷갈리지 말 것).

## 초기 셋팅 (맥마다 딱 한 번 — 5분)

**새 사람·새 맥이면 여기부터.** 순서대로 하고, 각 단계의 "됐다는 증거"를 확인한다.

| # | 할 일 | 됐다는 증거 |
|---|---|---|
| 1 | 크롬 버전 확인 — 주소창에 `chrome://version` | **144 이상**. 미만이면 업데이트부터(이 방식이 아예 안 된다) |
| 2 | 주소창에 `chrome://inspect/#remote-debugging` 열고 원격 디버깅 **켜기** | 같은 화면에 **`Server running at …`** 표시 |
| 3 | 터미널에서 `npx --version` | 버전 숫자가 찍힘(첫 연결 때 `chrome-devtools-mcp`를 자동으로 내려받는다). 안 찍히면 Node 설치(README 준비물) |
| 4 | 레포 폴더에서 `claude` 실행 | 레포 루트에 `.mcp.json`이 **이미 들어 있다** — 따로 만들 것 없음 |
| 5 | 처음 한 번 뜨는 MCP 서버 사용 승인 질문에 **승인** | — |
| 6 | **클로드 코드 재시작** | `mcp__chrome__*` 도구가 보인다 (`/mcp`로도 확인) |
| 7 | 클로드에게 "내 크롬 탭 보여줘" | 실제 내 탭들이 나온다 → **셋팅 끝** |

> 2번은 **크롬을 껐다 켜면 풀릴 수 있다.** 안 붙으면 제일 먼저 여기를 다시 본다.
> 연결 시 크롬이 **Allow 창**을 띄우면 사람이 승인한다.
> 📎 **도구 이름**: MCP 원래 이름은 `list_pages`·`navigate_page`·`take_snapshot`·`evaluate_script`·`take_screenshot` … 이고, **클로드 코드에서는 `mcp__chrome__` 가 앞에 붙는다**(`mcp__chrome__list_pages`). 아래에서는 원래 이름으로 적는다.

### 안 될 때

| 증상 | 원인 · 조치 |
|---|---|
| `mcp__chrome__*` 도구가 안 보인다 | 6번(재시작)을 안 했다. 재시작해도 없으면 `/mcp`로 서버 상태 확인 · 레포 폴더 안에서 `claude`를 켰는지 확인 |
| "No browser found" / 연결 실패 | 2번 옵트인이 꺼졌다. `chrome://inspect/#remote-debugging` 다시 확인 |
| 탭 목록이 **비어 있거나 낯설다** | 다른 크롬 프로필·창에 붙었다. **작업을 멈추고 사람에게 확인받는다** |
| 터미널 명령으로 탭을 보려는데 "못 붙었다"고 한다 | **정상이다** — 아래 참조 |

> ⚠️ **터미널 명령은 개인 크롬에 못 붙는다**
> Chrome 144의 옵트인은 연결 포트를 열지만 예전식 `/json/*` 주소는 열지 않는다(전부 404).
> 따라서 **실제 작업 통로는 MCP(`mcp__chrome__*`) 하나뿐**이다. 터미널에 남은 것은 **정책 판정 한 줄** — 크롬에 붙지 않고 같은 폴더의 `policy.json`만 읽으므로 언제나 동작한다:
>
> ```bash
> python3 .claude/skills/semi-auto-crawler/guard.py check <URL>   # 경로는 레포 맨 위 기준
> ```
