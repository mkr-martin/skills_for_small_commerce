# 반자동크롤러

공통 규칙(`브랜드_SSOT.md`(선택) · 원장 · 키 · 쓰기 안전 · 스크립트 불러오기) = [루트 CLAUDE.md](../../../CLAUDE.md) — 여기 다시 적지 않는다. 사람용 안내 = 같은 폴더 `사용법.md`.

🛑 **무인·예약 실행에서는 쓰지 않는다.** 사람이 화면을 보고 있는 세션에서만 — 사람이 옆에 있다는 것이 이 도구의 유일한 안전장치다(봇·크론·백그라운드 에이전트·자율 루프 금지).

**내가 볼 수 있는 화면을 손 대신 정리한다.** 뚫는 도구가 아니다.

## 0. 원리 · 초기 셋팅 (→ `references/setup.md`)

쓰던 크롬을 그대로 붙잡는 방식(Chrome 144+ 옵트인 `chrome://inspect/#remote-debugging` + MCP `--autoConnect`)이라 새로 띄운 빈 브라우저처럼 막히지 않는다. **새 사람·새 맥이면 `references/setup.md` 의 7단계 셋팅부터**(맥마다 1회 · "안 될 때" 진단표 포함 · 2번 옵트인은 크롬 재시작 시 풀릴 수 있다).

> ⚠️ **실제 작업 통로는 MCP(`mcp__chrome__*`) 하나뿐**이다 — 터미널 명령으로는 개인 크롬에 못 붙는다. 터미널에 남은 것은 정책 판정 한 줄(`python3 .claude/skills/semi-auto-crawler/guard.py check <URL>` — §3)뿐이다. `guard.py`·`policy.json` 은 이 스킬 폴더에 같이 들어 있어서 어디서 쓰든 판정할 수 있다.

## 1. 연결 확인 (매 작업 첫 단계)

1. `mcp__chrome__*` 도구가 보이는지 확인. 없으면 **레포 루트 `.mcp.json` 이 안 읽혔거나 클로드 코드 재시작이 필요**하다.
2. 크롬에서 `chrome://inspect/#remote-debugging` → 원격 디버깅 **허용**(최초 1회).
3. 연결 시 크롬이 **Allow 창**을 띄운다 → 사람이 승인.
4. 붙으면 현재 열린 탭 목록을 먼저 읽어 **어디에 붙었는지 사람에게 확인받는다.**

> ⚠️ 붙는 순간 **프로필 전체**(열린 탭·쿠키·로그인 상태)가 손이 닿는 범위다. 작업과 무관한 탭은 **읽지 않는다.**

## 2. 다섯 단계 (읽기 = 수집 작업)

1. **붙잡는다** — 새로 만들지 않고 쓰던 브라우저를 붙잡는다
2. **연다** — 목표 페이지로 이동
3. **화면을 읽는다** — HTML 파싱이 아니라 **사람이 보는 화면 기준**으로
4. **넘긴다** — 다음 페이지·스크롤로 반복
5. **정리한다** — 표로 만들어 저장

### 읽기 작업 프로토콜
- **먼저 한 페이지만.** 결과 모양을 사람에게 보이고 확인받은 뒤 전체로 늘린다.
- **항목 이름을 먼저 확정한다** (예: 제목·작성자·날짜·링크). 안 정하면 회차마다 표가 달라진다.
- **저장 형식을 먼저 정한다** (csv/md). 기본은 csv(UTF-8 BOM — 엑셀에서 한글이 안 깨진다). 저장 위치는 `output/수집/<yyyymmdd>_<이름>.csv`(결과물 폴더 규칙 = 루트 CLAUDE.md §2). 다른 스킬의 바탕으로 쓸 때는 그 스킬이 정한 건 폴더에.
- **사람 속도로.** 페이지 사이에 자연스러운 간격을 둔다. 초당 여러 페이지 금지.
- 결과가 이상하면 **브라우저 화면을 직접 보라고 안내**한다. 눈앞에 떠 있으니 어디서 멈췄는지 보인다.

## 2.5 ★ 구동 규약 — 화면을 어떻게 집는가

**화면 인식은 그림(비전)이 아니라 접근성(a11y) 트리 텍스트다.** `take_snapshot`은 접근성 트리를 글로 돌려준다. 공식 도구 설명도 *"Prefer taking a snapshot over taking a screenshot"*.

폼 조작에서 **비전은 도움이 안 되거나 오히려 해롭다**(접근성 트리 쪽이 훨씬 잘 완주한다). **스크린샷은 사람에게 보여줄 때만** 쓴다.

### 함정·표준 패턴·화면이 비어 보일 때 (→ `references/driving.md`)

핵심만: 클릭이 `did not become interactive` 로 죽으면 `evaluate_script` 로 **네이티브 `el.click()`** · uid 가 안 먹으면 스냅샷 재촬영 말고 **라벨 텍스트로 다시 찾는다** · 스냅샷은 `filePath` 로 저장하거나 아예 `evaluate_script` 로 필요한 것만 · 찾기·클릭·검증은 **1왕복**. 🛑 **`innerText` 가 비었다는 것은 봇 차단의 증거가 아니다**(Shadow DOM·JS 지연·iframe 을 다 확인한 뒤에만 "차단"이라 말한다). 표·코드 패턴·시행착오 목록·목록 수집 요령 전문 → `references/driving.md`.

### 🛑 evaluate_script는 판정을 건너뛰지 않는다

`evaluate_script`는 정책 판정을 **우회하는 통로가 아니다.** 스크립트가 하려는 일이 `fill`인지 `irreversible`인지를 먼저 판정하고, 판정 결과대로 행동한다.
특히 **🟡 irreversible을 `evaluate_script`로 몰래 실행하지 않는다** — 미리보기 → 사람 확정 절차는 도구가 뭐든 같다.

## 3. 쓰기 = 설정·발급 작업 (★ 여기가 "반자동")

관리자 화면 설정, API 키 발급 화면 찾아가기, 계정 세팅 같은 일. **소극적으로 굴지 말 것 — 대신 해줄 수 있는 건 적극적으로 한다.**

### 판정은 코드가 한다 — 먼저 물어본다

```bash
python3 .claude/skills/semi-auto-crawler/guard.py check <URL>      # 경로는 레포 맨 위 기준
```

행동 5종에 대해 🟢allow / 🟡confirm / 🔴deny 가 나온다. **이 판정이 이 문서보다 우선한다.** 정책은 같은 폴더 `policy.json` 이고, 거기 없는 사이트는 `default`(읽기·이동만 · 입력은 사람 확정 · 시크릿은 사람 직접)로 판정된다. 사이트를 더하고 싶으면 사장님이 `policy.json` 의 `sites` 에 한 항목 추가하면 된다 — `guard.py` 가 읽을 때 규칙(아래 불변식)을 검사해 어긋나면 판정을 거부한다.

| 행동 | 뜻 | 기본 태도 |
|---|---|---|
| `read` | 화면 읽기 | **적극적으로** |
| `navigate` | 메뉴 찾기·이동·탭 전환·검색 | **적극적으로** — 어디 있는지 찾아 헤매는 건 내 일이다 |
| `fill` | 이름·설명·수량·기간 등 **시크릿이 아닌 값** 입력 | **적극적으로** (🟢인 사이트에서) |
| `secret` | 토큰·비밀번호·API키·계좌 입력 | **언제나 사람이 직접.** 예외 없음 |
| `irreversible` | 삭제·결제·배포·대량발송·권한변경·주문확정 | 🟡면 **미리보기 → 사람 확정 후 실행 가능** · 🔴면 안 함 |

### 🟡 confirm 프로토콜 — 비가역도 할 수 있다 (사람이 요청했을 때)

**"되돌릴 수 없는 일은 사람 손으로"가 기본**이지만, 사람이 시키면 **확정을 받아가며** 대신 실행한다.

```
1) 미리보기 — 무엇이·어디에·어떻게 바뀌는지, 되돌리는 법까지 먼저 보여준다
2) 확정 대기 — 사람의 **별도 대답**을 기다린다. "ㅇㅋ" 같은 명시적 승인
3) 실행     — 딱 그 한 동작만. 여러 개를 묶어 실행하지 않는다
4) 확인     — 실행 후 화면을 읽어 결과를 보고한다
```

승인 없이 넘어가지 않는다. 그리고 **미리보기 없이 바로 실행하지 않는다.**

### 시크릿 취급 — 사람이 쓰되, 나머지는 내가 다 한다

토큰·키는 사람이 입력한다. 하지만 **거기까지 가는 길은 전부 대신 해준다**:
메뉴 찾기 → 생성 화면 진입 → 이름·설명·권한 범위·만료일 입력 → **"이제 여기서 값을 넣어주세요"** 로 넘김.

발급된 값이 화면에 떠도 **읽지도, 옮겨 적지도 않는다.** 대신 `python3 shared/setup_keys.py`("키 넣어줘")로 사장님 화면에 입력 창을 띄워 사람이 붙여넣게 한다(채팅창에 키를 붙여넣지 말라고 안내한다).

### 되돌리는 법 먼저
설정을 바꾸기 전에 **원래 값을 기록**하고, 되돌리는 방법을 함께 남긴다.

### 작업 흐름 예시 → `references/driving.md` 끝(저장 공간 만들기 대화 — 🟢 앞 단계는 대신 · 비가역은 미리보기 → 확정)

## 4. 하지 않는 것

- **로그인 없이 못 보는 자료**는 이 방식으로도 못 본다. 그건 원래 안 되는 게 맞다.
- **캡차·차단 우회 시도 금지.** 막히면 사람에게 알리고 멈춘다.
- **짧은 간격 반복 요청 금지.** 사이트 약관을 한 번은 확인한다.
- **작업과 무관한 탭 열람 금지.** 은행·개인메일 탭이 열려 있어도 읽지 않는다(정책상 `money`는 읽기부터 🔴).
- 로그인이 풀리면 **사람이 창에서 다시 로그인**하면 된다. 코드를 고칠 일이 아니다.

## 5. 오래 걸리는 작업

브라우저를 사람과 같이 쓰면 서로 방해한다. 긴 수집은 **자리를 비울 때** 돌리고, 그동안 다른 창 작업은 무관하다고 안내한다.

## 6. 누가 쓰나

**각자 자기 맥 · 자기 크롬으로** 쓴다. 계정을 넘기거나 공유하는 구조가 아니다.
- 이 스킬은 **로컬 크롬 + 사람의 Allow 승인**이 있어야 동작한다 → **무인 실행 불가**(봇·크론에서 못 쓴다). 그게 안전 근거다.
- 직원이 쓰면 **그 사람 계정으로 접근**하는 것이다. 자기 권한 밖 화면은 애초에 안 보인다.
