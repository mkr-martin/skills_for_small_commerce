# 반자동크롤러 사용법

## 1. 목적

로그인해야 보이는 화면 — 스마트스토어센터 · 쿠팡윙 · 카페24 관리자 · 인스타 · 카페 글 · 경쟁 쇼핑몰 목록 — 을 **내가 쓰던 크롬 그대로** 붙잡아, 손으로 복사·붙여넣기 하던 일을 클로드가 대신 읽고 표로 정리합니다.
관리자 화면에서 메뉴를 찾아가 설정하는 일(예: API 키 발급 화면까지 찾아가기)도 옆에서 보며 한 단계씩 같이 합니다.

다른 스킬(상세페이지 분석 · 릴스 레퍼런스 등)이 화면을 읽을 때도 이 스킬을 바탕으로 씁니다.

하지 않는 것: 캡차·차단 우회 · 결제 · 발송 · 삭제를 혼자 누르기 · 비밀번호나 API 키 입력.

## 2. 산출물

- **csv 한 장** — 레포 폴더의 `output_semi-auto-crawler/<날짜_시각>_<이름>/수집.csv`. 엑셀에서 바로 열립니다(한글 안 깨지게 UTF-8 BOM으로 저장).
- 또는 **md 메모** — 글 위주 자료일 때.
- 설정 작업이었다면 **"무엇을 바꿨나 · 원래 값 · 되돌리는 법"** 메모.

## 3. 스킬의 작동 방식

1. **붙잡는다** — 새 브라우저를 띄우지 않고, 지금 쓰고 있는 크롬에 붙습니다. 그래서 로그인도 그대로이고, 빈 브라우저처럼 막히지 않습니다.
2. **연다** — 원하는 페이지로 이동합니다.
3. **화면을 읽는다** — 사진이 아니라 화면의 글 구조(접근성 트리)를 읽습니다.
4. **넘긴다** — 다음 페이지·스크롤을 사람 속도로 반복합니다.
5. **정리한다** — 먼저 한 페이지만 표로 보여드리고, 모양이 맞으면 전체로 늘립니다.

쓰기(입력·클릭)는 **신호등**으로 정합니다. 같은 폴더의 `policy.json` 이 사이트마다 정해 두었고, `guard.py` 가 판정합니다.

| 신호 | 뜻 | 예 |
|---|---|---|
| 🟢 | 클로드가 바로 함 | 읽기 · 메뉴 이동 · (허용된 사이트에서) 이름·설명 입력 |
| 🟡 | 미리보기 → 사장님이 "ㅇㅋ" 한 뒤 한 동작만 | 저장 공간 만들기 같은 되돌리기 어려운 설정 |
| 🔴 | 클로드는 안 함, 사장님 손으로 | 비밀번호·API 키 입력 · 판매채널 관리자에서의 가격·쿠폰·주문 변경 · 은행 화면 |

정책에 없는 사이트는 "읽기·이동만, 입력은 확인받고, 비밀번호는 사장님이"로 다룹니다. 어떤 주소가 어떻게 판정되는지 직접 보고 싶으면:

```bash
python3 .claude/skills/semi-auto-crawler/guard.py check https://smartstore.naver.com
```

## 4. 설치법

0. 레포 받기·클로드 코드 열기 = 루트 [README 설치](../../../README.md#4-설치). 그다음 클로드 코드에 **"이 스킬 설치 도와줘"** 라고 하면 `python3 shared/doctor.py semi-auto-crawler` 로 아래 단계를 ✅/❌ 점검하며 ❌ 인 것만 하나씩 안내합니다. **아래 번호 = 점검 번호.**

1. **파이썬 3.9 이상** — 맥에 보통 들어 있습니다(없으면 처음 실행할 때 맥이 설치 창을 띄웁니다).
2. **Node(`npx`)** — 없으면 [nodejs.org](https://nodejs.org) 에서 LTS 설치 → 터미널 새로 열기.
3. **크롬 144 이상** — 주소창 `chrome://version` 으로 확인 · 낮으면 크롬 메뉴 → 도움말 → Chrome 정보에서 업데이트.
4. **크롬 연결 설정(`.mcp.json`)** — 레포에 들어 있습니다(숨김 파일). 처음 한 번 크롬 주소창 `chrome://inspect/#remote-debugging` 에서 원격 디버깅 **켜기** → 클로드 코드의 MCP 서버 사용 질문에 승인 → 클로드 코드를 한 번 껐다 켜기 → 크롬 **Allow** 창 허용.

API 키는 **필요 없습니다.**

**실행 한 줄**

> 내 크롬 탭 보여줘

내 탭 목록이 나오면 준비 끝. 그다음은 하고 싶은 일을 말로:

> 이 카페 게시판 1페이지 글 제목·작성자·날짜를 표로 정리해줘

자세한 7단계 셋팅과 됐다는 증거는 `references/setup.md`.

## 5. 안 될 때

| 증상 | 해볼 것 |
|---|---|
| 클로드가 "크롬 도구가 없다"고 한다 | 레포 폴더 **안에서** `claude` 를 켰는지 확인 → 클로드 코드 재시작 → `/mcp` 에서 chrome 서버 상태 확인 |
| "No browser found" · 연결 실패 | 크롬을 껐다 켜면 옵트인이 풀릴 수 있습니다. `chrome://inspect/#remote-debugging` 다시 켜기 |
| `npx` 가 없다고 나온다 | Node 설치(위 준비물) 후 터미널 새로 열기 |
| 탭 목록이 비었거나 내 탭이 아니다 | 다른 크롬 프로필·창에 붙은 것. 작업을 멈추고 쓰던 크롬 창을 앞으로 띄운 뒤 다시 |
| 로그인이 풀렸다 | 크롬 창에서 사장님이 다시 로그인하면 됩니다(코드를 고칠 일이 아님) |
| 화면엔 보이는데 "읽을 게 없다/차단됐다"고 한다 | 대개 차단이 아닙니다. "화면엔 보여, 다시 찾아봐"라고 말하면 숨은 영역(Shadow DOM·늦게 뜨는 화면·iframe)을 차례로 확인합니다 |
| 캡차가 떴다 | 사장님이 직접 풀고, 간격을 늘려 다시. 클로드는 캡차를 풀지 않습니다 |
| `guard.py` 가 "policy.json 규칙 위반"을 낸다 | `policy.json` 을 고치다 규칙(비밀번호 입력 허용 금지 등)을 어긴 것. 오류에 적힌 줄을 되돌리면 됩니다 |
