# 매대 점검

공통 규칙(`브랜드_SSOT.md`(선택) · 원장 · 키 · 쓰기 안전 · 스크립트 불러오기) = [루트 CLAUDE.md](../../../CLAUDE.md) — 여기 다시 적지 않는다.

## 하는 일
파일은 전부 `output_shelf-check/`(장부는 맨 위 · 회차 결과물은 `output_shelf-check/<yyyymmdd_hhmm>/`).
- `output_shelf-check/재고표.csv` — 우리가 파는 것의 기준(사장님이 채움): 제품 · 색 · 사이즈 · 상태(판매/단종) · 기준가 · 메모. 없으면 양식 `templates/재고표.csv` 를 그 자리로 복사해 주고(이미 있으면 덮어쓰지 않는다) 엑셀로 채우게 한다.
- `매대표.csv` — 채널에 실제 올라가 있는 것: 채널 · 제품 · 색 · 사이즈 · 재고수량 · 노출(Y/N) · 판매중(Y/N) · 품절표시(Y/N) · 판매가
  - **기본 = API 로 가져온다**(`scripts/fetch_shelf.py`). 키가 없는 채널은 사장님이 csv 를 직접 채운다(양식 `templates/`).
- `output_shelf-check/매핑표.csv` — 채널 옵션(예: "색상:블랙 / 사이즈:M")을 재고표의 (제품·색·사이즈)에 잇는 장부.
  열: 채널 · 상품번호 · 채널 상품명 · 채널 옵션명 · 제품 · 색 · 사이즈 · 확인(Y=쓰기 / N=빼기 / 빈칸=아직)

🛑 **읽기 전용 — 쓰기 API 호출 금지.** 품절 처리·다시 열기·재고·가격 변경 API 를 부르는 코드를 만들지도, 대신 실행하지도 않는다. 사장님이 원하면 `사용법.md` 의 「참고 — 옵션 열고 닫기」를 보여 주고 채널 관리자에서 직접 하게 한다.

## 순서

### 처음 한 번(또는 채널에 상품·옵션이 새로 생겼을 때) — 매핑
1. 쓰는 채널 키가 있는지는 스크립트가 알려 준다("키 없음" 한 줄 — 값은 보지 않는다). 없으면 "키 넣어줘"(= `python3 shared/setup_keys.py --only <채널>`). 카페24는 로그인이 한 번 필요하다 — `python3 shared/channels/cafe24.py login`(사장님 화면에 창이 뜬다 · 문의 스킬에서 이미 했으면 생략).
2. 실행: `python3 .claude/skills/shelf-check/scripts/fetch_shelf.py --map`
   → `output_shelf-check/매핑표.csv` 가 생긴다. 제품·색·사이즈는 재고표·`브랜드_SSOT.md` 의 색 별칭으로 자동 추정해 채우고, 못 찾은 칸은 비워 둔다. 이미 있는 줄은 건드리지 않고 새 옵션만 덧붙는다.
3. **클로드가 매핑표를 보여 주고 애매한 줄만 물어본다.**
   - 제품·색·사이즈가 다 찬 줄은 표로 묶어 "이대로 맞나요?" 한 번에 묻는다.
   - 빈 칸이 있는 줄만 한 줄씩: "카페24 '하루양말 데일리 3켤레' 의 '색상:형광 / 사이즈:M' 은 재고표의 어느 칸인가요? (매대 점검에서 뺄 거면 '빼기')"
   - 답을 받아 그 줄의 칸을 채우고 `확인=Y`, 빼기면 `확인=N`. 사장님이 답하지 않은 줄에 Y 를 적지 않는다.
   - 색 이름이 채널마다 달라 추정이 빗나갔으면 `브랜드_SSOT.md` 의 "색 별칭" 줄에 더하자고 제안한다(다음 `--map` 부터 자동).

### 매일
1. `python3 .claude/skills/shelf-check/scripts/fetch_shelf.py` → `output_shelf-check/<yyyymmdd_hhmm>/매대표.csv`(실행할 때마다 새 회차 폴더)
   - 매핑표의 `확인=Y` 줄만 쓴다. 매핑표에 없는 옵션은 넣지 않고 "🔵 새 옵션 N건 — `--map` 다시" 로 알린다 → 위 매핑 순서를 그 줄만 다시.
   - 한 채널에 같은 칸(제품·색·사이즈)을 상품 둘 이상으로 올렸으면(예: 일반 판매 + 공동구매) 그 상품들은 채널 칸이 `스마트스토어 · <상품명 앞 20자>` 로 갈라져 따로 판정된다(앞 20자까지 같으면 끝에 `#상품번호`). 매대표 열은 그대로다. 한 상품 안에서 옵션 둘이 같은 칸이면 "첫 줄만 썼어요" 경고 — 매핑표에서 하나만 Y 로 고치자고 말한다.
2. `python3 .claude/skills/shelf-check/scripts/shelf_check.py`(인자 없이 — 재고표 = 맨 위 `재고표.csv`, 매대표 = `output_shelf-check/` 아래 가장 최근 회차 폴더. 다른 걸 점검하려면 `shelf_check.py <재고표.csv> <매대표.csv>`)
   - 저재고 기준을 바꾸려면 `--low 20`. 안 주면 `브랜드_SSOT.md`(선택)의 "저재고 기준", 그 줄이 비어 있으면 10.
3. 출력을 그대로 보여 주고, 급한 순서(🆘 → 🔴 → 🟠 → 💰)로 사장님이 지금 할 일을 한두 줄로 말한다. 🔵 새 옵션 경고가 있었으면 함께 말한다.
4. 결과는 같은 회차 폴더의 `결과.csv`(엑셀에서 열림). 같은 매대표로 다시 돌리면 덮어쓴다.

### 키가 없는 채널
`templates/매대표.csv` 양식으로 사장님이 채운다. 채널 엑셀을 받아 왔다면 열 이름을 매대표 양식에 맞춰 새 csv 로 만들어 준다(원본은 건드리지 않는다). API 로 만든 매대표와 합칠 때는 같은 열로 줄만 이어 붙인 새 파일을 만든다.

## 채널 값 → 매대표 열
| 열 | 카페24 | 스마트스토어 | 쿠팡 |
|---|---|---|---|
| 재고수량 | 품목 quantity (재고 사용 안 함이면 빈칸 → ❓) | 옵션 stockQuantity | amountInStock |
| 노출 | 상품·품목 display 둘 다 T | 채널상품 전시상태 ON | 상품 상태 승인완료·부분승인완료 |
| 판매중 | 상품·품목 selling 둘 다 T | 상품 상태 SALE 이고 옵션 usable | onSale |
| 품절표시 | 품목 display_soldout | 항상 Y(채널이 재고 0 을 스스로 막는다고 봄 — 문서 미확인) | 항상 Y(같은 이유 — 문서 미확인) |
| 판매가 | 판매가 + 품목 추가금액 | 할인가(즉시할인 적용 · 고객이 내는 값) + 조합형 옵션가 | 아이템 salePrice |

## 판정 규칙
- 🆘 오버셀: 재고 0 이하인데 판매중이고 품절표시가 꺼져 있음. `품절표시` 열이 없으면 "재고 0 & 판매중"이면 오버셀로 단순 판정하고 출력에 그 사실을 적는다.
- 🔴 비정상 공실: 판매 상품인데 닫혀 있음(판매중지 또는 재고 0 + 품절표시 켜짐). 재고표 상태가 단종이거나 재고표에 없는 칸(둘 다 ⚪)이면, 또는 메모에 "의도"가 적혀 있으면 경보에서 뺀다.
- 🟠 저재고: 판매중이고 재고가 기준 미만.
- 💰 가격 어긋남: 기준가와 판매가가 둘 다 있고 다름.
- ⚫ 미노출(안 보이는 옵션, 품절 아님) · ❓ 재고수량 칸이 비었거나 숫자 아님(0으로 치지 않고 따로 표시) · 🔵 재고표에 없는데 열려 있음.

## 지킬 것
- 쓰는 곳은 `output_shelf-check/` 폴더뿐(매핑표·매대표·결과). 재고표·채널 원본 파일을 고치지 않는다.
- 매핑표는 사장님 장부다 — `--map` 은 새 줄만 덧붙이고, 클로드는 사장님이 답한 줄만 고친다.
- 열 이름이 어긋나 에러가 나면 에러 문구의 "있는 열"을 보고 사장님 파일 헤더를 알려 달라고 한 뒤 양식에 맞춰 준다.
