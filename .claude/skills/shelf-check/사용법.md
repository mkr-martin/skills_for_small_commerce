# 매대 점검 사용법

## 1. 목적
"재고는 0인데 쇼핑몰에서 계속 팔리고 있는 옵션", "이유 없이 닫힌 옵션", "곧 떨어질 옵션", "가격이 잘못 올라간 옵션"을 한 번에 찾습니다. 매일 아침 쇼핑몰 관리자를 하나씩 열어 보던 일을, 채널에서 표를 받아 와 재고표와 맞대는 두 줄 실행으로 바꿉니다.

## 2. 산출물
터미널에 이런 화면이 나옵니다(가상 가게 "하루양말" 예시).

```
🆘 오버셀 1건 — 재고 0인데 판매중 (가장 급함: 계속 팔려서 마이너스가 됩니다)
   - 하루몰 / 하루양말 데일리 검정 M  (재고 0)

🔴 비정상 공실 2건 — 닫혀 있는데 단종도 의도된 품절도 아님 (확인 필요)
   - 하루몰 / 하루양말 데일리 검정 L  (재고 0)
   - 하루스토어 / 하루양말 울 베이지 L  (재고 0)

🟠 저재고 2건 — 재고 10개 미만 (판매중)
   - 하루몰 / 하루양말 데일리 흰색 L  (재고 4)
   - 하루스토어 / 하루양말 데일리 검정 M  (재고 9)

💰 가격 어긋남 1건 — 기준가와 판매가가 다름
   - 하루몰 / 하루양말 울 베이지 M  기준가 9,900 / 판매가 8,900

===== 채널별 히트맵 =====

  ▮ 하루몰 / 하루양말 데일리
                 M     L
    흰색       🟢    🟠
    검정       🆘    🔴
    회색       ⚪      ·

범례:  🟢 정상 | 🟠 재고<10 | 🔴 품절 | ⚪ 단종 | 🆘 오버셀 | ⚫ 미노출 | ❓ 확인불가 | 🔵 재고표 밖 | · 미등록
저장: output/매대/20261014/결과.csv
```

레포 폴더의 `output/매대/` 에 이런 파일이 있습니다(모두 엑셀에서 열림).

| 파일 | 무엇 |
|---|---|
| `output/매대/재고표.csv` | 우리가 파는 것의 기준 — 사장님이 채움(4절 5번) |
| `output/매대/매핑표.csv` | 채널 옵션 ↔ 재고표 칸 연결 장부(처음 한 번 만들고, 새 옵션이 생기면 덧붙임) |
| `output/매대/<날짜>/매대표.csv` | 그날 채널에서 받아 온 옵션별 재고·노출·판매상태·판매가 |
| `output/매대/<날짜>/결과.csv` | 점검 결과 한 칸에 한 줄 |

## 3. 스킬의 작동 방식
1. **가져오기** — `fetch_shelf.py` 가 채널 API(카페24 · 스마트스토어 · 쿠팡)로 상품·옵션(색·사이즈)·재고수량·노출·판매중·품절표시·판매가를 **읽기만** 합니다. 키가 없는 채널은 건너뛰고 "키 없음" 한 줄을 띄웁니다.
2. **매핑** — 채널마다 옵션 이름이 다릅니다("블랙" / "검정" / "BLACK"). `output/매대/매핑표.csv` 가 채널 옵션 하나하나를 재고표의 (제품 · 색 · 사이즈) 한 칸에 이어 줍니다. 처음엔 재고표와 `브랜드_SSOT.md` 의 색 별칭으로 자동 추정해 채우고, 애매한 줄만 클로드가 물어봅니다. 맞는 줄에 `확인=Y`, 점검에서 뺄 줄에 `확인=N`.
3. **매대표 만들기** — 매일 실행하면 `확인=Y` 인 줄만 써서 `output/매대/<날짜>/매대표.csv` 를 만듭니다. 매핑표에 없는 새 옵션이 보이면 매대표에 넣지 않고 "🔵 새 옵션 N건 — `--map` 다시" 로 알립니다. 한 채널에 같은 옵션을 상품 둘로 올렸으면(예: 일반 판매 + 공동구매) 채널 칸을 `스마트스토어 · <상품명 앞 20자>` 처럼 상품별로 나눠 따로 점검합니다.
4. **점검** — `shelf_check.py` 가 채널 × 제품 × 색 × 사이즈 칸마다 재고표와 매대표를 대조합니다. 급한 순서는 오버셀 → 비정상 공실 → 저재고 → 가격 어긋남입니다.
5. 재고표에서 "단종"이거나 메모에 "의도"라고 적은 품절은 경보에서 빠집니다(일부러 닫아 둔 것이므로).
6. 재고수량 칸이 비었거나 숫자가 아니면 0으로 치지 않고 ❓로 따로 표시합니다(카페24에서 "재고 사용 안 함"인 옵션도 ❓).
7. 쇼핑몰을 고치지 않습니다. 품절 처리 · 가격 수정은 사장님이 채널 관리자에서 직접 합니다.

## 4. 설치법

0. 레포 받기·클로드 코드 열기 = 루트 [README 설치](../../../README.md#4-설치). 그다음 클로드 코드에 **"이 스킬 설치 도와줘"** 라고 하면 `python3 shared/doctor.py shelf-check` 로 아래 단계를 ✅/❌ 점검하며 ❌ 인 것만 하나씩 안내합니다. **아래 번호 = 점검 번호.**

1. **파이썬 3.9 이상** — 맥에 보통 들어 있습니다(없으면 처음 실행할 때 맥이 설치 창을 띄웁니다).
2. **채널 키**(쓰는 채널만 · 없어도 됨) — 클로드 코드에 **"키 넣어줘"** → 뜨는 창에 붙여넣기(발급 방법 = 루트 [README '키 발급'](../../../README.md#5-키-발급)) · 🛑 키는 채팅창에 붙여넣지 않습니다. 키 없이 쓰려면 매대표.csv 를 직접 채웁니다(§5 「키 없음」 항목 또는 SKILL.md 「키가 없는 채널」).
3. **파이썬 패키지 bcrypt**(스마트스토어 키를 넣었을 때만) — 터미널에서 한 번: `python3 -m pip install -r .claude/skills/shelf-check/requirements.txt`
4. **카페24 로그인**(카페24 를 쓸 때만 · 한 번) — 클로드 코드에 **"카페24 로그인"** → 브라우저에서 로그인·동의 → 넘어간 페이지 주소를 뜨는 창에 붙여넣기. 게시판 읽기 + 상품 읽기 권한을 한 번에 받습니다(③④ 중 한쪽에서 했으면 다시 안 해도 됨). 2주 넘게 안 쓰면 다시.
5. **재고표.csv** — `output/매대/재고표.csv` 에 둡니다. 양식 = `.claude/skills/shelf-check/templates/재고표.csv` (열: 제품, 색, 사이즈, 상태(판매/단종), 기준가, 메모) — 그 자리로 복사해 엑셀로 채웁니다(클로드에게 "재고표 양식 꺼내줘" 해도 됩니다).
6. (선택) **브랜드_SSOT.md** — 비어 있어도(템플릿 그대로) 작동합니다. 채우면 결과가 내 가게에 맞춰집니다. "브랜드_SSOT.md 같이 채우자" 라고 하면 대화로 함께 채웁니다. (저재고 기준 · 색 별칭을 여기서 읽습니다 — 비어 있으면 저재고 10개 · 별칭 없음)

**처음 한 번 — 매핑**(설치가 끝난 뒤)

1. `python3 .claude/skills/shelf-check/scripts/fetch_shelf.py --map` → `output/매대/매핑표.csv`
2. 클로드 코드에 "매핑표 확인해줘" — 표를 보여 주고 애매한 줄만 물어봅니다. 답하면 `확인=Y` / `N` 을 적어 줍니다(엑셀로 직접 고쳐도 됩니다).

**그다음부터 매일 두 줄**

```
python3 .claude/skills/shelf-check/scripts/fetch_shelf.py
python3 .claude/skills/shelf-check/scripts/shelf_check.py output/매대/재고표.csv output/매대/<오늘날짜>/매대표.csv
```

첫 줄이 끝나면 두 번째 줄을 날짜까지 채워서 화면에 보여 줍니다. 클로드 코드에서 "매대 점검해줘" 한마디로도 됩니다. 저재고 기준을 바꾸려면 끝에 `--low 20` (안 쓰면 `브랜드_SSOT.md` 의 "저재고 기준", 아직 안 채웠으면 10).

## 5. 안 될 때
- **스마트스토어 · 쿠팡 "읽기 실패 — HTTP 403" 뒤에 "호출 IP 가 허용 목록에 없습니다"**: 지금 인터넷 IP 가 그 채널에 등록돼 있지 않습니다(집·카페 와이파이가 바뀌면 IP 도 바뀝니다). 터미널 `curl -s https://api.ipify.org` 로 IP 를 보고 네이버 커머스API센터 · 쿠팡 윙 OPEN API 화면에 등록하세요 — 루트 [README '내 IP 확인'](../../../README.md#내-ip-확인).
- **"키 없음 — 루트 README '키 발급'"**: 그 채널 키가 아직 없습니다("키 넣어줘"). 키 없이 하려면 **`매대표.csv` 를 직접 채우세요(기존 방식)** — `output/매대/` 에 두고, 양식 `templates/매대표.csv`, 열: 채널, 제품, 색, 사이즈, 재고수량, 노출(Y/N), 판매중(Y/N), 품절표시(Y/N), 판매가. 채널 관리자에서 받은 상품 엑셀의 맨 윗줄(헤더)을 클로드에게 보여 주면 이 양식에 맞춰 줍니다.
- **"🔵 새 옵션 N건 — `--map` 다시"**: 채널에 옵션이 새로 생겼습니다. `fetch_shelf.py --map` 을 다시 돌리고, 새로 붙은 줄만 확인하세요(이미 확인한 줄은 그대로 남습니다).
- **"매핑표에 확인=Y 이고 … 줄이 없어요"**: 매핑표 확인을 아직 안 했습니다. 4절 「처음 한 번 — 매핑」 2번.
- **카페24 "로그인이 필요합니다" / "리프레시 토큰이 만료됐습니다"**: 클로드 코드에 "카페24 로그인" 을 다시(2주 넘게 안 쓰면 만료).
- **스마트스토어 "bcrypt 가 없습니다"**: `python3 -m pip install -r .claude/skills/shelf-check/requirements.txt`.
- **"한 상품 안에서 옵션 둘 이상이 같은 칸으로 이어져 첫 줄만 썼어요"**: 매핑표에서 한 상품의 두 옵션을 같은 (제품·색·사이즈)로 적었습니다. 맞는 쪽만 `확인=Y`, 나머지는 `N` 으로.
- **"필요한 열이 없어요"**: 에러 문구 아래에 지금 파일의 열 이름이 나옵니다. 양식과 이름이 다르니, 그 줄을 클로드에게 보여 주세요.
- **한글이 깨짐**: 엑셀에서 "CSV UTF-8"로 다시 저장하세요(윈도 엑셀의 기본 CSV도 자동으로 읽긴 합니다).
- **전부 "미등록(·)"으로 나옴**: 매핑표의 제품·색·사이즈 글자가 재고표와 조금이라도 다릅니다(띄어쓰기 포함). 재고표 글자 그대로 맞추세요.
- **💰 가격 어긋남이 옵션 추가금 때문에 뜸**: 매대표 판매가는 "판매가 + 옵션 추가금"입니다. 재고표 기준가도 그 옵션의 최종 가격으로 적으세요.
- 이 스킬은 알려만 줍니다. 품절 처리·가격 수정은 채널 관리자에서 직접 하세요.

## 참고 — 옵션 열고 닫기

> 이 스킬은 **읽기 전용**이라 옵션을 닫거나 여는 코드가 없습니다. 아래는 "API 로도 할 수 있다"는 참고일 뿐입니다. 평소엔 채널 관리자 화면에서 손으로 하세요.

**어떤 API 로 가능한가** (각 채널 공식 문서에서 확인한 것만)

| 채널 | 하는 일 | API |
|---|---|---|
| 카페24 | 옵션(품목) 진열·판매 상태 바꾸기 | `PUT /api/v2/admin/products/{상품번호}/variants/{품목코드}` (display · selling) |
| 카페24 | 옵션 재고·품절표시 바꾸기 | `PUT /api/v2/admin/products/{상품번호}/variants/{품목코드}/inventories` (quantity · display_soldout) — 상품 쓰기 권한 필요 |
| 스마트스토어 | 옵션 재고·옵션가·할인가 바꾸기 | `PUT /v1/products/origin-products/{원상품번호}/option-stock` |
| 스마트스토어 | 상품 판매 상태 바꾸기 | `PUT /v1/products/origin-products/{원상품번호}/change-status` |
| 쿠팡 | 옵션 판매 중지 / 재개 | `PUT …/marketplace/vendor-items/{옵션ID}/sales/stop` · `…/sales/resume` |
| 쿠팡 | 옵션 재고 바꾸기 | `PUT …/marketplace/vendor-items/{옵션ID}/quantities/{수량}` |

**왜 위험한가**
- **잘못 닫으면 매출이 0**이 됩니다. 옵션 하나를 잘못 골라 닫아도 그 옵션 매출은 바로 끊기고, 아무도 모르면 며칠씩 갑니다.
- **잘못 열면 오버셀**입니다. 재고가 없는데 열면 주문이 들어오고, 취소·사과·페널티로 이어집니다.
- **채널마다 반영이 늦습니다.** "성공" 응답을 받아도 화면·주문 가능 상태에 바로 반영되지 않을 수 있어, 성공했다고 믿고 넘어가면 어긋납니다.
- 채널마다 규칙이 다릅니다. 예) 카페24는 "품절표시"를 꺼 두면 재고가 0 이어도 주문이 계속 들어와 재고가 마이너스가 됩니다(카페24 문서). 스마트스토어 옵션 재고 변경 API 는 판매가·할인 정보를 함께 보내는 방식이라, 잘못 보내면 가격·할인까지 바뀔 수 있습니다.

**그래도 자동화하려면, 먼저 이것부터**
1. **두 번 확인** — 바꿀 옵션 목록과 "지금 값 → 바꿀 값"을 화면에 보여 주고 사람이 "예"라고 한 뒤에만 실행. 한 번에 한 묶음만.
2. **되돌리기 기록** — 바꾸기 직전 값(재고·판매상태·품절표시)을 파일에 먼저 남기고, 그 파일로 원래대로 되돌리는 방법을 먼저 만든다.
3. **바꾼 뒤 다시 읽어 확인** — 잠시 기다렸다가 같은 옵션을 다시 조회해 정말 바뀌었는지 본다.
