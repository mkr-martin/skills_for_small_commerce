# 문의 모으기

공통 규칙(`브랜드_SSOT.md`(선택) · 원장 · 키 · 쓰기 안전 · 스크립트 불러오기) = [루트 CLAUDE.md](../../../CLAUDE.md) — 여기 다시 적지 않는다.

> **이 스킬은 문의를 모으기만 한다.** 답변 보내기도 API 로 가능하지만 고객에게 바로 나가는 일이라 위험해서 코드는 넣지 않았다. 만들 재료(엔드포인트·필수값·안전장치 설계·먼저 답할 질문)는 `완성하기.md` 에 있다.
> 🛑 사장님이 "보내는 기능 만들자" 고 하면 바로 코드를 쓰지 말고 `완성하기.md` 의 질문부터 한 개씩 묻는다.

## 하는 일
채널마다 흩어진 미답변 문의를 `output/문의/문의함.csv`(결과물 폴더 · 루트 CLAUDE.md §2) 한 표로 모은다. 답변은 사장님이 쓴다 — 표의 `답변` 칸에 쓰거나 대화로 같이 다듬은 뒤, 각 채널 관리자 화면에 사장님이 직접 붙여넣는다.
초안을 저절로 만들지 않는다. 사장님이 "이 문의 답 같이 써 줘" 하면 그때 대화로 돕는다(`브랜드_SSOT.md` 가 채워져 있으면 그것을 근거로 · 아직 비어 있어도 돕는다 · 모르는 사실은 지어내지 말고 물어본다).

## 순서
1. 실행한다(경로는 레포 맨 위 기준).
   ```
   python3 .claude/skills/inquiry-inbox/scripts/fetch.py
   ```
   며칠 전까지: `--days 14` · 한 채널만: `--channel naver|coupang|cafe24`.
2. 출력을 그대로 보여 준다. 채널마다 한 줄 — "새로 N건 추가" · "키 없음 — 건너뜀" · "실패 — 이유".
   - 키 없음 → "키 넣어줘"(= `python3 shared/setup_keys.py --only <채널>`)를 권한다. 발급 방법은 루트 README '키 발급'.
   - 카페24 처음이면 → 게시판 번호부터: `python3 .claude/skills/inquiry-inbox/scripts/fetch.py --cafe24-boards` 결과를 보여 주고, 사장님이 고르면 `python3 shared/setup_keys.py --key CAFE24_INQUIRY_BOARDS` 를 실행한다(번호는 사장님 화면의 창에 넣는다).
   - 카페24 "로그인이 필요합니다" · "리프레시 토큰이 만료됐습니다" → `python3 shared/channels/cafe24.py login` 을 실행한다(타임아웃 넉넉히 — 사장님이 브라우저에서 동의하고 돌아온 주소를 창에 붙여넣을 때까지 기다린다). 주소·코드를 채팅으로 받지 않는다.
3. 새로 들어온 문의를 채널·종류별로 짧게 요약한다(급해 보이는 것 — 배송 지연·환불·파손 — 먼저).
4. 사장님이 답을 같이 쓰자고 하면 대화로 돕고, 확정한 답을 `답변` 칸에 적고 `상태` 를 사장님이 정한 말(예: 답함)로 바꿔 준다.

## 문의함.csv
열(순서 고정): `id · 채널 · 종류(상품문의/고객문의/고객센터) · 접수일 · 상품 · 고객(가림) · 문의 원문 · 답변 · 상태`
- 스크립트는 새 id 의 줄만 **맨 아래에 덧붙인다.** 이미 있는 줄(사장님이 쓴 답변·상태·덧붙인 열)은 건드리지 않는다.
- 🛑 표를 손으로 고칠 때도 기존 줄을 지우거나 순서를 바꾸지 않는다 — 고칠 칸만 고친다. `id` 열 이름은 바꾸지 않는다.
- 고객 이름은 가려서 적는다(김*루). 전화번호·주소는 담지 않는다.

## 지킬 것
- 읽기만 한다. 답변 등록·수정 API 를 부르는 코드를 즉석에서 쓰지 않는다(임시 스크립트·curl 포함). 보내기를 원하면 `완성하기.md`.
- 공식 문서에 없는 엔드포인트를 추측해 부르지 않는다.
