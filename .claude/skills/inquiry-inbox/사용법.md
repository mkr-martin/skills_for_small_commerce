# 문의 모으기 사용법

> **이 스킬은 문의를 모으기만 합니다.** 답변 보내기도 API 로 할 수 있지만, 고객에게 바로 나가는 일이라 위험해서 코드는 넣지 않았습니다. 직접 만들고 싶다면 재료와 먼저 답할 질문이 [`완성하기.md`](./완성하기.md) 에 있습니다.

## 1. 목적
네이버 스마트스토어 · 쿠팡 · 카페24 관리자를 하나씩 열어 "답 안 한 문의 있나" 확인하던 일을, 한 번의 실행으로 표 한 장에 모읍니다. 답변은 사장님이 직접 씁니다(클로드와 대화로 다듬어도 됩니다).

## 어디까지 모으나
| 채널 | 모으는 것 | 안 모으는 것 |
|---|---|---|
| 네이버 | 고객문의(주문한 고객의 1:1 문의 · 커머스 API "고객 문의 조회") · 상품 Q&A(상품 페이지 아래 공개 Q&A · "상품 문의 목록 조회") | 톡톡 |
| 쿠팡 | 상품별 고객문의 · 쿠팡 고객센터 문의 | — |
| 카페24 | 사장님이 고른 게시판의 글(상품 문의·1:1 문의 게시판 번호를 처음 한 번 정함) | 게시판 밖 문의 |

네이버 톡톡은 커머스 API 와 다른 별도 시스템이라 들어 있지 않아요. 톡톡 메시지를 받으려면 톡톡 챗봇 API 에 웹훅을 따로 등록해야 해서, 미답변을 한 번에 조회하는 이 스킬 방식으로는 가져올 수 없어요.

## 2. 산출물
레포 폴더의 `output_inquiry-inbox/문의함.csv` 한 장 — 엑셀로 열립니다(가상 가게 "하루양말" 예시).

| id | 채널 | 종류 | 접수일 | 상품 | 고객 | 문의 원문 | 답변 | 상태 |
|---|---|---|---|---|---|---|---|---|
| naver:qna:77 | 네이버 | 상품문의 | 2026-10-13 10:02 | 하루양말 발목 3족 | har**** | 사이즈 넉넉한가요? | | 미답변 |
| coupang:cs:1015668177:1027082307 | 쿠팡 | 고객센터 | 2026-10-13 14:20 | 하루양말 데일리 L | | [취소/반품] 반송했는데 확인 부탁 | | 미답변 |

- `답변`·`상태` 칸은 사장님 메모용입니다. 답을 써 두고 상태를 "답함" 등으로 바꿔 쓰세요. 다시 모아도 이 칸은 그대로 남습니다.
- 열을 더 만들어도(예: 메모) 지워지지 않습니다. 단, `id` 열 이름은 바꾸지 마세요.
- 엑셀에서 저장할 때는 형식을 **CSV UTF-8** 로 고르세요.
- 엑셀로 `문의함.csv` 를 엽니다.

## 3. 스킬의 작동 방식
1. 키를 넣어 둔 채널만 부릅니다. 키가 없는 채널은 "키 없음" 한 줄을 남기고 건너뜁니다.
2. 채널마다 공식 API 로 **아직 답하지 않은** 문의만 읽습니다(기본 최근 7일).
   - 네이버: 고객 문의 + 상품 문의
   - 쿠팡: 상품별 고객문의 + 쿠팡 고객센터 문의(판매자 답변이 필요한 것). 한 번에 7일씩 나눠 읽습니다.
   - 카페24: 사장님이 고른 게시판에서 댓글이 아직 없는 글(공지·답변글·삭제글 제외)
3. 이미 표에 있는 문의(id 가 같음)는 건너뛰고, 새 문의만 표 맨 아래에 덧붙입니다.
4. 고객 이름은 가려서(김*루) 적고, 전화번호·주소는 담지 않습니다.
5. 읽기만 합니다. 고객에게 아무것도 보내지 않습니다.

## 4. 설치법

0. 레포 받기·클로드 코드 열기 = 루트 [README 설치](../../../README.md#4-설치). 그다음 클로드 코드에 **"이 스킬 설치 도와줘"** 라고 하면 `python3 shared/doctor.py inquiry-inbox` 로 아래 단계를 ✅/❌ 점검하며 ❌ 인 것만 하나씩 안내합니다. **아래 번호 = 점검 번호.**

1. **파이썬 3.9 이상** — 맥에 보통 들어 있습니다(없으면 처음 실행할 때 맥이 설치 창을 띄웁니다).
2. **채널 키**(쓰는 채널만 — 하나 이상) — 클로드 코드에 **"키 넣어줘"** → 뜨는 창에 붙여넣기(발급 방법 = 루트 [README '키 발급'](../../../README.md#5-키-발급)) · 🛑 키는 채팅창에 붙여넣지 않습니다.
   - 네이버: 애플리케이션 ID · 시크릿 / 쿠팡: Access Key · Secret Key · 업체코드 / 카페24: 쇼핑몰 ID · Client ID · Client Secret · Redirect URI
3. **파이썬 패키지 bcrypt**(네이버 키를 넣었을 때만) — 터미널에서 한 번: `python3 -m pip install -r .claude/skills/inquiry-inbox/requirements.txt`
4. **카페24 로그인**(카페24 를 쓸 때만 · 한 번) — 클로드 코드에 **"카페24 로그인"** → 브라우저에서 로그인·동의 → 넘어간 페이지 주소를 뜨는 창에 붙여넣기. 게시판 읽기 + 상품 읽기 권한을 한 번에 받습니다(③④ 중 한쪽에서 했으면 다시 안 해도 됨). 2주 넘게 안 쓰면 다시.
   - 그다음 문의 게시판 고르기: 클로드 코드에 **"카페24 문의 게시판 골라줘"** → 번호 목록을 보고 고른 번호(예: `6,9`)를 뜨는 창에 넣습니다.
5. (선택) **브랜드_SSOT.md** — 비어 있어도(템플릿 그대로) 작동합니다. 채우면 결과가 내 가게에 맞춰집니다. "브랜드_SSOT.md 같이 채우자" 라고 하면 대화로 함께 채웁니다. (답을 같이 쓸 때 근거가 됩니다)

**실행 한 줄** — 클로드 코드에서: **"미답변 문의 모아줘"**
(직접 실행: `python3 .claude/skills/inquiry-inbox/scripts/fetch.py` · 며칠 전까지 `--days 14` · 한 채널만 `--channel coupang`)

## 5. 안 될 때
| 보이는 말 | 할 일 |
|---|---|
| `네이버` · `쿠팡: 실패 — HTTP 403` 뒤에 `호출 IP 가 허용 목록에 없습니다` | 지금 인터넷 IP 가 그 채널에 등록돼 있지 않습니다(집·카페 와이파이가 바뀌면 IP 도 바뀝니다). 터미널 `curl -s https://api.ipify.org` 로 IP 를 보고 네이버 커머스API센터 · 쿠팡 윙 OPEN API 화면에 등록 — 루트 [README '내 IP 확인'](../../../README.md#내-ip-확인) |
| `네이버: 키 없음` 등 | 그 채널 키가 아직 없습니다. "키 넣어줘" 로 넣으세요. |
| `bcrypt 가 없습니다` | 터미널에서 `python3 -m pip install -r .claude/skills/inquiry-inbox/requirements.txt` 한 번. |
| `네이버: 실패 — HTTP 401` · IP 문구 없는 `403` | 커머스API센터에서 애플리케이션 상태·API 권한(문의)을 확인하세요. |
| `쿠팡: 실패 — HTTP 401` | 맥 시계가 맞는지(시스템 설정 → 날짜 및 시간 → 자동) 확인하고, 키를 다시 복사해 붙여넣으세요. |
| `카페24 로그인이 필요합니다` · `리프레시 토큰이 만료됐습니다(2주)` | 클로드 코드에 "카페24 로그인" 을 다시 합니다. |
| `CAFE24_INQUIRY_BOARDS 가 비어 있습니다` | "카페24 문의 게시판 골라줘" 로 번호를 넣으세요. |
| `카페24: 실패 — HTTP 403` | 개발자센터 앱의 권한에 "게시판 읽기"가 있는지, 쇼핑몰에 앱이 설치돼 있는지 확인하세요. |
| 엑셀에서 한글이 깨짐 · `읽을 수 없습니다` | 엑셀 저장 형식을 **CSV UTF-8** 로 다시 저장하세요. |
| 쿠팡 `상품` 칸이 `등록상품 123…` | 쿠팡 상품별 문의 API 가 상품 이름을 주지 않아 번호로 적습니다(정상). |
