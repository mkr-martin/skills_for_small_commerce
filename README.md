# 스몰 커머스 스킬 묶음

> **가장 쉬운 시작** — 이 레포를 내려받아([§4 설치](#4-설치)) 그 폴더에서 클로드 코드를 연 뒤, **"이 프로젝트에 대해 설명해줘"** 라고만 말하세요.
> 클로드가 스킬을 쭉 소개하고, 번호로 고르면 그 스킬 설치를 한 단계씩(내 맥 상태를 점검해 가며) 안내합니다.
> 아래는 직접 읽어 보고 싶은 분을 위한 설명입니다.

작은 온라인 가게 사장님이 **클로드 코드**에게 바로 시킬 수 있는 일 다섯 가지를 스킬로 묶었습니다.
상세페이지 뜯어보기 · 잘 된 릴스 분석 · 흩어진 문의 모으기 · 품절인데 팔리는 칸 찾기 — 그리고 그 바탕이 되는 "내 크롬으로 같이 보기".

## 1. 이게 뭔가

- **클로드 코드 · 크롬**만 있으면 됩니다.
- 커다란 "통째 에이전트"를 깔게 하는 대신, **설치가 쉽고 효과가 큰 일만 골라 개별 스킬로** 나눴습니다. 필요한 것만 골라 쓰면 됩니다.
- 데이터베이스·서버가 없습니다. 결과는 이 폴더 안 **`output_<스킬>` 폴더**에 실행마다 폴더 하나씩 파일(md · csv)로 남고, 엑셀이나 텍스트 편집기로 열어 봅니다([§7](#7-결과물--output_스킬-폴더)).
- 이미 Hermes(오픈소스 AI 에이전트 프로그램) 같은 에이전트를 쓰고 계시면, 이 스킬들을 거기에 연결해 써도 됩니다.

## 2. 스킬 다섯

⓪ 은 바탕 도구이고, 나머지 넷은 두 묶음입니다.

- **배우는 스킬(①②)** — 남의 콘텐츠(상세페이지 · 릴스)를 뜯어보고, 결과를 파일로 남깁니다.
- **운영하는 스킬(③④)** — 내 가게 데이터(문의 · 매대)를 채널 API 로 **읽기만** 합니다. 고객에게 보내거나 쇼핑몰을 바꾸는 코드는 없습니다.

| 묶음 | 스킬 | 한 줄 | 필요한 키 | 화면 | 이렇게 말하세요 |
|---|---|---|---|---|---|
| 바탕 | ⓪ [반자동크롤러](.claude/skills/semi-auto-crawler/사용법.md) | 로그인해야 보이는 화면을 내 크롬 그대로 읽어 표로 | 없음 | 없음(터미널 · csv) | "내 크롬 탭 보여줘" |
| 배우기 | ① [상세페이지 분석](.claude/skills/detail-page/사용법.md) | 상세페이지 한 장을 글로 옮기고 왜 팔리는지 풀어냄 | 없음 | 결과 폴더(md) | "이 상세페이지 분석해줘 <URL>" |
| 배우기 | ② [릴스 레퍼런스](.claude/skills/reels-reference/사용법.md) | 릴스를 씬별로 분해하고, 훅 유형을 분류하고, 내 브랜드 적용 아이디어까지 | Gemini | 결과 폴더(md) | "이 릴스 레퍼런스 분석해줘 <URL>" |
| 운영 | ③ [문의 모으기](.claude/skills/inquiry-inbox/사용법.md) | 채널마다 흩어진 미답변 문의를 한 표로 모음(답은 사장님이 각 채널에서) | 채널 API | csv 를 엑셀로 | "미답변 문의 모아줘" |
| 운영 | ④ [매대 점검](.claude/skills/shelf-check/사용법.md) | "품절인데 팔림"을 고객보다 먼저 잡음 | 채널 API(③과 같은 키) · 없으면 csv | 없음(터미널) | "매대 점검해줘" |

스킬마다 `사용법.md` 가 같은 순서로 되어 있습니다: 목적 → 산출물 → 작동 방식 → 설치법 → 안 될 때.

> 상세페이지 분석의 7원칙은 자청의 마케팅 부트캠프에서 배운 틀입니다.

> **③ 은 반쯤 완성된 스킬입니다.** 문의를 모으는 데까지만 하고, 답변 보내기는 넣지 않았습니다 — API 로 가능하지만 고객에게 바로 나가는 일이라 위험해서입니다. 직접 만들고 싶으면 재료와 먼저 답할 질문이 [`완성하기.md`](.claude/skills/inquiry-inbox/완성하기.md) 에 있습니다. ④ 의 옵션 열고 닫기도 같은 이유로 [참고 문서](.claude/skills/shelf-check/사용법.md#참고--옵션-열고-닫기)만 둡니다.

|---|---|---|
| 맥 | — | — |
| 클로드 코드 | 터미널에서 `claude --version` | [claude.com/claude-code](https://claude.com/claude-code) 안내대로 설치 |
| 크롬 **144 이상**(⓪①② 만) | 크롬 주소창에 `chrome://version` | 크롬 메뉴 → 도움말 → Chrome 정보에서 업데이트 |

**스킬별 키**

| 스킬 | 필요한 키 |
|---|---|
| ⓪ 반자동크롤러 | **키 없음** |
| ① 상세페이지 분석 | **키 없음** |
| ② 릴스 레퍼런스 | **Gemini API 키**(필수) |
| ③ 문의 모으기 | 쓰는 채널의 API 키(네이버 · 쿠팡 · 카페24 중 쓰는 곳만) — **모으기만** 합니다 |
| ④ 매대 점검 | 채널 API 키(③과 같은 키) — **읽기만** 합니다 · 키가 없으면 csv 두 장으로도 됩니다 |

키 넣기는 클로드 코드에 **"키 넣어줘"** 한마디 → 뜨는 창에 붙여넣기. 발급 방법은 아래 [§5](#5-키-발급).

내 맥에 무엇이 준비됐는지는 클로드 코드에 **"이 스킬 설치 도와줘"** 라고 하면 ✅/❌ 로 점검해 줍니다(직접: `python3 shared/doctor.py all`).

## 4. 설치

### 방법 1(기본) — ZIP 다운로드

1. 이 레포 페이지의 초록색 **`<> Code`** 단추 → **`Download ZIP`**.
2. 다운로드 폴더의 `skills_for_small_commerce-main.zip` 을 더블클릭해 풉니다.
3. 풀린 폴더를 원하는 곳(예: 문서 폴더)으로 옮깁니다. 폴더 이름 끝의 `-main` 은 그대로 둬도 됩니다.
4. 터미널에서 그 폴더로 들어가 `claude` 를 실행합니다.
   - 터미널이 처음이면: 터미널에 `cd ` (cd 다음 한 칸 띄움)를 치고, Finder 에서 그 폴더를 터미널 창에 끌어다 놓은 뒤 엔터 → `claude` 엔터.
   - 또는 Finder 에서 폴더를 Dock 의 터미널 아이콘에 끌어다 놓아도 그 폴더에서 터미널이 열립니다.
5. 클로드 코드가 열리면 이렇게 말해 보세요:

   > 이 프로젝트에 대해 설명해줘

   그다음은 클로드가 한 단계씩 안내합니다.
6. **크롬을 쓰는 스킬(⓪①②)을 쓸 때만** 크롬 연결을 처음 한 번 설정합니다 → [반자동크롤러 설치법](.claude/skills/semi-auto-crawler/사용법.md#4-설치법). 끝나면 "내 크롬 탭 보여줘" 라고 해서 탭 목록이 나오면 준비 끝입니다. ③④ 만 쓸 거면 건너뜁니다.

> ⚠️ **숨김 폴더 `.claude` 를 지우지 마세요.** Finder 에서는 안 보이지만 들어 있습니다(⌘⇧. 를 누르면 보입니다). 스킬이 전부 그 안에 있습니다.

**업데이트** — 새 ZIP 을 받아 풀고, 예전 폴더에서 **내 것만** 새 폴더로 옮깁니다.

- **내 결과물은 `output_` 로 시작하는 폴더들만 새 폴더로 옮기세요**(분석 · 문의함 · 재고표 · 매대 기록이 전부 그 안에 있습니다).
- 그 밖에 내 것 세 개: `브랜드_SSOT.md`(채웠으면) · `.env`(넣어 둔 키) · `cafe24.token.json`(카페24 로그인 — 있으면). `.env` 와 `cafe24.token.json` 은 숨김 파일이라 Finder 에서 ⌘⇧. 로 보이게 한 뒤 옮깁니다.

### 방법 2 — git clone (git 을 쓰는 분만)

```bash
git clone https://github.com/martingoh/skills_for_small_commerce.git && cd skills_for_small_commerce && claude
```

업데이트는 그 폴더에서 `git pull`. `브랜드_SSOT.md` 를 채웠다면 pull 전에 `git stash` → `git pull` → `git stash pop` 순서로 합니다. 내 파일(`.env` · `output_<스킬>` 폴더)은 git 에 올라가지 않게 막혀 있어 그대로 남습니다.

## 5. 키 발급

> 🛑 **키는 비밀번호와 같습니다.** 채팅창 · 문서 · 스크린샷 · 카톡에 남기지 마세요. 클로드에게도 채팅으로 붙여넣지 않습니다.

**넣는 법(공통)** — 아래에서 키를 발급받은 뒤, 클로드 코드에 **"키 넣어줘"** 라고 말합니다. 맥 입력 창이 키마다 하나씩 뜨면 붙여넣고 **확인**(모르는 칸은 **건너뛰기**). 마지막에 "네이버 ✅ / 쿠팡 ❌ 없음 …" 처럼 채널별 상태가 한 번 뜹니다. 한 채널만 넣으려면 "네이버 키만 넣어줘".

### 내 IP 확인

**네이버 · 쿠팡만 해당.** 네이버 커머스 API 와 쿠팡 윙 OPEN API 는 **등록한 IP 에서 오는 호출만 받습니다**(등록 안 된 IP 면 `HTTP 403 … Your ip address … is not allowed`). 키를 만들 때 지금 이 맥이 인터넷에 나가는 IP 를 등록하세요. IP 는 터미널에 한 줄로 확인합니다:

```bash
curl -s https://api.ipify.org
```

> ⚠️ **집·카페·매장 와이파이가 바뀌면 IP 도 바뀝니다.** 어느 날 ③④ 가 `HTTP 403` 을 내면 위 한 줄로 IP 를 다시 확인해 그 채널 화면에 새로 등록하세요(스킬이 403 오류 끝에 같은 안내를 붙여 줍니다).

### Gemini (② 릴스 레퍼런스)

1. 구글 계정으로 **Google AI Studio**([aistudio.google.com](https://aistudio.google.com)) 에 로그인합니다.
2. 왼쪽 또는 위의 **Get API key(API 키 가져오기)** 를 누릅니다.
3. **API 키 만들기** 를 눌러 새 키를 만들고 복사합니다.
4. 클로드 코드에 "키 넣어줘" → `GEMINI_API_KEY` 창에 붙여넣기.

무료 사용량 안에서 시작할 수 있고, 한도·요금은 AI Studio 화면에서 확인합니다.

### 네이버 스마트스토어 (③ 문의 · ④ 매대)

1. **네이버 커머스API센터**([apicenter.commerce.naver.com](https://apicenter.commerce.naver.com)) 에 스마트스토어센터 계정으로 로그인합니다.
2. **애플리케이션 등록** 에서 새 애플리케이션을 만들고, 내 스토어를 연결합니다.
3. 쓸 API 권한(문의 · 상품 조회)을 고릅니다.
4. **호출 IP 등록** — 애플리케이션의 API 호출 IP 칸에 위 [내 IP 확인](#내-ip-확인)으로 본 IP 를 넣습니다.
5. "키 넣어줘" → **애플리케이션 ID** · **애플리케이션 시크릿** 을 각 창에 붙여넣기.
6. 네이버는 서명 도구가 하나 더 필요합니다 — 터미널에서 한 번: `python3 -m pip install -r .claude/skills/inquiry-inbox/requirements.txt`

### 쿠팡 (③ 문의 · ④ 매대)

1. **쿠팡 윙**([wing.coupang.com](https://wing.coupang.com)) 에 로그인합니다(사업자 인증을 마친 판매자 계정이어야 발급됩니다).
2. 오른쪽 위 **업체명(내 아이디)** 클릭 → **추가판매정보** → **OPEN API 키 발급** 에서 약관 동의 후 발급합니다.
3. 연동 방식은 **자체개발(직접입력)** 을 고르고, **호출 IP 등록** — 위 [내 IP 확인](#내-ip-확인)으로 본 IP 를 넣습니다(쿠팡은 등록한 IP 에서만 호출을 받습니다 · 와이파이가 바뀌면 다시 등록).
4. "키 넣어줘" → 화면 아래의 **Access Key · Secret Key · 업체코드(A 또는 C로 시작)** 를 각 창에 붙여넣기. 업체코드도 남에게 보이지 않게 — 스킬 오류 문장에는 `***` 로 가려져 나옵니다.
5. 키는 유효기간(180일)이 있습니다. 만료되면 같은 화면에서 재발급하고 "키 넣어줘" → 덮어쓰기.

### 카페24 (③ 문의 · ④ 매대)

1. **카페24 개발자센터**([developers.cafe24.com](https://developers.cafe24.com)) 에 가입·로그인합니다.
2. **앱 만들기** 로 내 쇼핑몰 전용 앱을 만들고, 권한은 **읽기 둘만** 고릅니다 — 게시판 읽기(③) · 상품 읽기(④).
3. 앱 설정의 **Redirect URI**(로그인 후 돌아올 주소)를 하나 등록합니다. 로그인 때 그 주소창의 주소만 복사해 쓰므로 실제로 열리는 페이지가 아니어도 됩니다.
4. "키 넣어줘" → **쇼핑몰 ID**(관리자 아이디 = `xxx.cafe24.com` 의 xxx) · **Client ID** · **Client Secret** · **Redirect URI**(3번과 글자 하나까지 같게)를 각 창에 붙여넣기.
5. **로그인 한 번** — 클로드 코드에 **"카페24 로그인"** → 브라우저에 동의 화면이 열리면 쇼핑몰 관리자로 로그인해 **동의** → 넘어간 페이지의 주소 전체를 복사해 뜨는 창에 붙여넣기(1분 안에). 그 뒤로는 자동으로 연장됩니다(2주 넘게 안 쓰면 다시 로그인). 레포를 업데이트한 뒤 카페24에서 `HTTP 403`(권한 없음)이 나오면 스킬이 쓰는 권한이 늘어난 것이니 로그인을 한 번 다시 합니다.
6. ③ 문의를 쓰면: "카페24 문의 게시판 골라줘" → 번호 목록을 보고 고른 번호를 창에 넣습니다.

세 채널 중 **쓰는 곳만** 하면 됩니다. 키가 비어 있으면 스킬이 "어느 채널 키가 없는지"를 알려 주고 그 채널을 건너뜁니다.

## 6. `브랜드_SSOT.md` 쓰는 법

`브랜드_SSOT.md` 는 레포에 처음부터 들어 있는 **빈 템플릿**입니다. **채우는 건 선택** — 아직 비어 있어도(템플릿 그대로) 모든 스킬이 작동합니다. 채워져 있으면 결과가 내 가게에 맞춰집니다(① "오늘 고칠 것" · ② "우리 가게 훅 후보" 등). 비어 있으면 그 칸에 "브랜드_SSOT.md 가 비어 있어 일반 제안" 이라고 적고 일반 제안을 냅니다.

- 스킬들은 가게 사실을 **`브랜드_SSOT.md` 에 적힌 것만** 근거로 씁니다. 적히지 않은 사실은 지어내지 않습니다.
- **맨 위 다섯 절만 채워도 충분합니다** — 파는 것 · 배송 · 교환/반품 · 자주 오는 질문 10 · 말투 3.
- 나머지(판매 채널 · 옵션 표 · 기준가 · 소구점 · 저재고 기준 …)는 "있으면 더 좋은 것"에 접혀 있습니다. 쓰는 스킬이 생길 때 채우면 됩니다.
- 채운 모습은 `브랜드_SSOT_예시.md`(실제 가게 "알타핏"이 채운 모습)를 보세요.
- 말투는 실제로 고객에게 보냈던 답 3개를 그대로 붙여넣는 게 가장 정확합니다.
- 비밀번호·키·계좌번호는 여기 적지 마세요.

클로드에게 "브랜드_SSOT.md 같이 채우자"라고 말하면 질문하면서 함께 채워 줍니다.

## 7. 결과물 — `output_<스킬>` 폴더

결과물은 `output_<스킬>/<시각>_<이름>/` 에 파일로 쌓입니다(원장·재고표 같은 장부는 `output_<스킬>/` 맨 위). 폴더는 스킬을 처음 실행할 때 저절로 생기고, git 에 올라가지 않으며, 업데이트 때는 `output_` 로 시작하는 폴더만 새 폴더로 옮기면 됩니다.

```
output_detail-page/
├── 원장.md                     지금까지 분석한 건 — 한 건 = 한 줄
├── 20261015_0905_하루양말/      한 번 실행 = 폴더 하나(날짜_시각_이름)
└── 20261016_1420_가을신상/
```

`원장.md` 는 한 건 = 한 줄인 표입니다. 스킬은 맨 아래에 한 줄씩만 더하고, 이미 있는 줄은 고치지 않습니다.
